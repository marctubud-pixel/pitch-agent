## 完整方法

首轮从三案九个候选起步，分别记录坐标、怕与想要的动机、创意连接、选法、七道闸、短顺准及声律版本、独立可懂与行为盲读。六项机械检查保留失败及修正结果。A 换过一次创意连接，B、C 按各自版本保留票据。三案首次送双团前共有 20 个独立会话。创作侧的取舍单独记载，用户偏好等待实际选择。

### 稿件 9ceff02d

- A　山线与瓶身合读可理解，但“只有一瓶茶高”的尺度创意与虎跑泉水仍主要并列；请重写主副文联系，并让高度反差传达更明确的感受。
- B　配方事实清楚，但包装前脸主副文连续重复，尚未形成所称的分享触发；请调整信息分工，分享效果留待验证。
- C　“看着茶念出虎跑”缺少说话动机，同事随即误会也显刻意；请重写触发与转折，同时保留准确的配方解释。

### 稿件 4453bf97

- A　主句“只有一瓶茶高”的尺度趣味偏弱；副文“认出青屿”预设品牌认知，看、认、转、查看的指令也过密。需重写主句和副文，建立山线与配方选择的联系。
- B　有效传播票的主副文分工为3分。“挑茶时，你挑过水吗？”可能引出为何挑水的期待，副文只交代用了什么水；需调整问答，使提问与可陈述的配方事实相称。
- C　有效文案及用户票有多项3分。“你的茶上怎么写着虎跑”指代欠明确，对话开口和交流意味偏刻意，且与设定选茶情景联系较间接；需修改对白和触点承接。

### 稿件 502d7d69

- A　文案岗主副文协作3分仍有效：从“茶里用虎跑泉水”转到“下回……找青屿的这道山线”较跳跃，副文需返工。“茶里用虎跑泉水”属于允许的事实表述，无须仅因未写“配方”而退稿。
- B　文案和传播岗有效票有3分，品牌及传播岗要求修改。“想把一瓶茶的用水也弄明白”与主问句重复，还可能暗示完整交代用水；需收窄并精简。
- C　多岗有效票有3分。“青屿无糖茶，配方用了虎跑泉水”插入代买对话较生硬，紧接“那帮我也拿一瓶”易产生水源促成跟选的暗示；需调整对话与人物动机。
