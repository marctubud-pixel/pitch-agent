# 本地简报HTTP合同与联调

规范版本：1.1.0。当前七阶段前端复用较早正式前端的DTO与Brief封装思路，完成项目读取、新建、任务卡保存和确认。本轮追加范围见[七阶段研究接续](seven-stage-research.md)；保留已认可的页面和默认浏览器演示。

## 启动与数据

先执行根`npm run setup:frontend`。在两个终端分别运行：

```sh
npm run dev:brief
npm run dev:http
```

浏览器打开`http://127.0.0.1:4420/`。前者创建独立的`.data/brief-workbench.sqlite`，只绑定127.0.0.1:4182，并显式允许4420来源；后者启动当前应用并设置完整API根`http://127.0.0.1:4182/api/v1`。与默认`npm run dev`使用同一前端端口，切换前先停止自己启动的4420进程。旧4417及原scratch保持。

需要隔离数据库或端口时，直接执行`node tools/workbench/brief-server.mjs --db PATH --port PORT --origin http://127.0.0.1:FRONTEND_PORT`，并为前端设置对应`VITE_WORKBENCH_API_URL`。数据库及SQLite旁文件属于本地运行数据，Git不备份。重启时使用同一数据库恢复，不复制或重开旧业务run。

## 服务边界

`brief-server.mjs`复用业务域和SQLite存储，单独提供`/api/v1/capabilities`、项目列表／单项及历史修订读取、新建项目、`revise-task-card`和`confirm-task-card`。请求字段白名单、128 KiB正文上限、loopback Host和明确来源共同限制本地入口。默认不创建执行器或供应商，不恢复、派发或推进任何已有job；显式研究配置仅允许当前请求指定的研究任务；写入旧完整服务前必须另行验收，不能以其通用入口代替本服务。

前端先验证`surface: brief-v1`、`executionAvailable: false`才写入，实际握手前显示未接通。项目、概览、任务卡及七阶段状态从同一后端快照投影；没有封面就显示空态，没有研究或创意产物就保持未开始。确认简报会使导航指向研究，但不创建研究任务。已有job或产物的历史项目不属于这轮投影合同，明确拒绝采用，避免把旧执行链显示为当前七阶段。

旧项目继续保留无workflow的历史身份，新建项目使用proposal-seven-v1，研究原件及来源接入范围见上述接续。此为单机开发服务，原生记录作者固定`local-operator`，不是前端所选人类或Agent身份，也不是生产账号鉴权。前端本地游客权限仍生效，服务端多用户授权另行实现。助手、协作写入、模式更新和后续生产动作明确未接入。Brief文本提取沿用本地实际解析能力。

## 同版与重试

类型、正文、来源、工作方式、人工节点及汇报时间在创建时一并存储。简报保存保留旧隐藏字段及来源，类型和正文同次更新。原生`revision`是乐观锁；`expectedRevision`绑定用户提交时的基准，冲突返回真实当前修订，不自动覆盖或重基。

每次命令使用稳定`commandId`。发送前将原请求存入按API地址与本地角色隔离的sessionStorage；刷新后在页面上方显示待核对及保留的简报，用户点击“核对原提交”才按原命令重放。未决记录存在时阻止不同的新命令，核对全过程锁定当前角色；冲突保留原文，核完可结束记录。会话存储不可用时在发送前拒绝写入，关闭标签或清除会话存储后的恢复不在承诺内。刷新后重试从原始修订重建确定性的请求体，不加入当前时间、随机值或前端actor。同一命令同内容重放不会重复写入，真实回执标记`replayed`；同命令不同内容拒绝。网络中断、写入5xx或成功响应无法完整解析均按未知结果处理，保留原命令核对。原保存／确认已被新稿替代时，重放返回冲突，不把旧正文与新修订号合成可编辑状态。

创建ID由命令ID派生，原生初始修订为0；列表`catalogRevision: 0`仅兼容旧接口，不承诺目录CAS。创建重放查初始输入身份，当前任务卡按真实head读取。

## 业务版本与原件

旧存储每次保存都会生成不可变原生任务卡。前端按确认边界折叠业务版本：未确认期间连续保存仍显示v1，确认后再编辑才显示待确认v2。全部原生任务卡、ID、修订及审计留存；这不是覆写旧记录。真实修改时间和确认时间取原生审计；旧封装没有可信时间时显示未知，不补猜历史作者。

Brief附件目前只保存原文和元数据，`fileAvailable: false`，不提供伪造原文件下载。独立品牌资料原件持久化尚未接通，选择这类文件会在创建项目之前明确拒绝；未选品牌资料的简报流程可用。文件跨设备恢复、模型读取用途及资源权限另验。
