## 实际输入与检查

按项目固定`skills/ui-review/SKILL.md`、其20原则／验证方法／视觉事实核对和`docs/specs/ui-system.md`执行。

先看主Agent最终截图：`research-final-1280-light.png`与`research-final-910-dark.png`。随后独立临时Chrome实际打开4423的新协议项目，检查中文1280×1000浅色与910×1000深色、100%缩放。独立脚本与截图保留在本机本轮scratch；[独立回执](evidence/seven-stage-20261111/ui-independent-result.json)随仓库保存。

实际确认：

- 七阶段导航顺序明确；研究保持“未开始”，五板块均显示无已登记结论，没有用示例图假装有产物。
- r7方法版本、执行尚未启用、独立读者回环未接入与交接不能通过分别可见。页面阅读顺序为阶段→研究入口→限制与核验→空态→来源。
- “打开研究工作区”可以打开；“生成研究框架”实际禁用，未触发模型请求。
- 来源对话框可打开和取消；默认用途为`unclassified`，“附加到论点”实际禁用；空链接与摘录说明已清楚区分原文保存和来源核实。
- 1280与910实测document.scrollWidth等于视口宽；910深色吸顶栏top=0。没有pageerror；独立检查期间POST请求数量为0。
- 重要r7限制文字为12px。实际浅色rgb(100,101,108)对body rgb(241,241,238)对比度5.126381828425005；深色rgb(156,156,150)对body rgb(11,11,10)为7.135026902144545。该段普通文字满足4.5:1；不外推整页WCAG。

主Agent来源落库响应丢失→刷新→同体恢复回执另见[主执行回执](evidence/seven-stage-20261111/UI-RECEIPT.json)。我只复核该回执和SourcesView恢复控制：存在未决请求时禁新增并阻止添加弹窗重开遮挡核对入口。为保持本任务只读，本人没有重复该写入路径，不能把主回执计作独立写入验收。回执中的3项来源是多轮保留的合成验收记录，不是实际研究结论。

早期整页截图中吸顶栏出现在中部，是未先归零滚动位置的采集条件差异；最终截图与独立实测均位于top=0，不据旧采集图判页面错位。
