# 多候选视觉探索与阶段选优 v3

2026-10-23 用户确认。当前为人工编排验证协议，非自动调度系统已实现。与旧分类、参考确认方式冲突时以本文件为准；保留历史记录。

## 方向与任务卡

三个方向分别为稳健延续、产品特征放大、用户氛围/情绪放大。它们是探索岗位，不天然保证差异。搜图前每方向写核心主张、视觉机制、品牌依据、节点依据及与另两案的区别；主题先于画面。稳健方向若已突出某种用户氛围，第三案须用不同机制，而非更换同一画面的道具。

节日、节气任务必须有与节点相关的画面证据，可为场景、器物、纹理、天气、行为；文字辅助，不要求脱离文案唯一识别具体节日。检查画面证据是否服务主题，不能仅加节点文字或小标签；也不要求堆满节庆符号。普通场景换标题即可通用于其他节点，且缺乏视觉关联时退回。

## 多候选流程

1. 多创作Agent分方向/素材来源搜集，集中去重。每方向至少多个可查看候选，记录原始来源、借鉴作用、禁止照搬部分与转译假设。跨行业参考不充当用户偏好或趋势证据。
2. 四位独立裁判按参考适配性审核；四位对应对抗角色核查。先判断用途卡与图的关系，再排序，不把原图制作精美等同于本任务适配。主参考、互补参考、备用候选分别标明；辅助素材不单独承担完整创意。
3. 对通过的方向形成三个视觉机制不同的草图，不仅换左右位置。允许共用已验证的品牌/节点约束。候选均保留，评分前不向裁判透露推荐或排名。
4. 草图先看主角、层级、元素、构图、文字长度位置以及品牌/节点关系，再评形式与表达；不因未精修的纹理字体扣成稿分。三方向总览检查在参考与草图阶段都做。
5. 各方向选最高且达标的草图进入下一阶段；仅最高但未达标不晋级。当前梦之蓝验证止于草图评审，无精绘授权。

## 评分与裁定

参考按《参考图评审试行规则_v2》适用性尺度和必评项审核，不自动套成稿平均分。先合格后按本职适配评分比较，近似候选记录取舍，保留备用。无需对局部辅助参考强制评分不适用项。

草图/成稿保留《视觉评审平均分准入_v1》：视觉、品牌、用户、传播四位，各给1—5整体分，S=Σs/4，未舍入S≥4.0；4.5更优目标。诊断分不重复计算，不新增所有角色≥4或任一≥3的数值限制。缺票不缩小分母。

必要条件独立检查：核心主题成立、品牌/产品表达适配任务、节点有有效画面关联、创意未妨碍核心理解。明确不成立即阻断；关键未知待核，不靠高美术分抵消。保留可见证据与影响，不将个人风格偏好自动视为硬伤。

对抗团不评分，批评包含规则、画面证据、影响、修改验收条件；先独立找问题再核对评分断言。总监采纳/驳回均说明理由，不改原票。修改稿绑定新图哈希，受影响部分重新评，旧分不得自动继承。图像不变的口径复核与新稿复评分开。

创作、评分、对抗、总监职责分离。独立评分不带创作历史、作者推荐、旧分或其他裁判结论；给必要任务事实与比较图。模拟用户/传播不是真人测试，同模型多Agent不是异构独立验证。

## 模式、停止和交付

自动模式内部推进到任务授权的终点；辅助模式参考候选与评审汇报后由用户确认再进入草图，其他节点可配置。用户明确授权一次执行到草图评审时无需在参考阶段重复确认，但不能越过精绘边界。

沿用常规最多三次修改；达到限次或任务预算上限暂停受影响方向，列最佳现有稿和未解决问题，不降低标准凑齐通过。未提供可核验费用时记未知，不编造预算。每阶段保存检查点，失败只重试受影响步骤；任务ID、输入、图、来源、模型可知信息、原分与修改原因留档。

交付区分提案概念稿和投放成品。主提案展示选用稿，独立过程页保存全部参考、草图、淘汰及裁定，支持按单一方向追溯。

## 本轮审计补充

主参考的资格与选优由保存的评分记录校验，总监不能以个人倾向把适用性未通过候选升为主参考；同分按任务适配理由取舍，较低分图可限定为辅助。参考到草图的交接须冻结主/辅/备用及转译范围；生成后纠正必须另存版本并记录发生时间，不能倒写历史。梦之蓝V3发生过C主参考选优纠正，原记录保留供审计。
