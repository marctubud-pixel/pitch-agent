# 对抗审查试行规则

> **当前出图准入更新（2026-10-23）**：后续生成视觉稿按[视觉评审平均分准入 v1](视觉评审平均分准入_v1.md)执行：事前指定裁判整体分等权平均≥4.0，4.5为更优目标；有据硬性问题核查成立仍退修。以下历史实验的逐项≥4/暂不设阈值不再作为出图数值门槛；参考适用性与文案等其他阶段不自动改用平均分。历史记录保留。


参考、草图、精修三阶段适用，草图为重点；当前只完成参考阶段小样本，见output/evaluation/adversarial-trial/测试总结.md。

- 视觉/品牌/用户模拟/传播各一名独立评分与一名对应独立对抗，均不参与创作。对抗先自行看图/卡，再看本职评分；不打分，不凑批评。
- 对抗报告字段：质疑的原句、图/卡证据、反证或证据不足或偏好、任务影响、严重度、当前阶段、建议验证。已知退回或明确条件不当新增漏判。
- 独立总创意总监裁定：采纳当前/采纳后续/不采纳并解释/待核；不直接改评分、不平均票决。当前采纳影响准入时回创作修改、原岗位复评。无批评不等于全局无缺陷。
- 参考看用途转译和重复；草图看核心主张、主次、品牌/场景堆叠；精修看兑现及产品、字形、材质、实际尺寸。问题是否阻断看影响，非元素数量或个人偏好。
- 所有角色同模型配置并不构成多模型验证。0新增挑战、合成错误检出、真实漏判修复收益分开记录。保持参考适用分>=4且无关键硬退/未知等原规则，不因对抗团存在降低门槛。

## 三组独立测试后的补充（2026-10-22）

证据：`output/evaluation/parallel-trials/测试总结.md`。参考/草图/Slogan三组输入规则同批冻结、交错执行；12评分+12对应对抗+独立总监。参考用途获限定准入，草图及三个Slogan均未综合通过；对抗新增挑战0，不能据此宣称增益已验证。原规则首段“当前只完成参考”是历史状态，当前已扩展到低保真草图与文案小样本，精修仍未测试。

### 文案双团

- 评分四角色：文案（主张、中文表达）、品牌（品牌连接、任务及事实）、用户模拟（情感可理解、受众关联）、传播（简明记忆潜力、区别于同组方向）。每角色配置独立对应对抗，不与创作共享讨论历史。
- 对抗先自行阅读冻结文本，记录初读，再领取对应评分；针对具体肯定提出有证据的反驳，不打分，不为了数量制造争议。
- 文案总监负责创作修订；独立总创意总监负责采纳/延后/拒绝/待核，不直接调分。有效阻断交回修改，并由原评分角色重新验收。
- 换品牌、换节日、三案互换是诊断工具，不能机械用“能换”直接否决；不得因无促销CTA扣品牌主题分。主标题与副标题作为组合检查，同时标注哪一层提供节点/品牌联系。
- 单案门槛与整组差异分开签发。整组比较固定列出主张、情绪、品牌语义桥梁、视觉载体假设；不以换同义词或不同画风充当不同创意。后两项是待成图验证假设，不当作图文效果已兑现。

### 分阶段和证据门槛

草图视觉维度改为“主次与构图”“主载体对主题的兑现”，不再沿用参考的“可借鉴/转译可行”。传播差异必须绑定实际对照与范围；缺资料用unknown阻断，不给中间分凑结果。材料就绪检查在评审前完成。品牌关联须指出语义联系；名称字眼不自动等于品牌专属，也不要求绝对不可替换。

### 输出与审计

原件永久保留。后续评分status固定为scored/unknown/not_applicable，决策需给明确阶段和准入范围；发现其他枚举先退格式校验，不直接交自动流程。初读与材料包保存时间和摘要，评分后不能覆盖。实际新增、已有覆盖、人工构造错误检出分别统计；0新增不构成质量认证。用户及传播均为模拟意见，真人效果另需实测。

独立总监审计补充：原协议未锁定已评分枚举，因此assessed/rated不是追溯违规。下一轮使用[双团评审输出契约v2](../evaluation/双团评审输出契约_v2.md)，明确required、blocking、hard_rejects、comparison_scope/ids与准入scope。品牌关联3/4、主张差异3/4仍待配对校准，不强令文案添加品牌字，不把任务内不同偷换为市场独创。当前是文档契约，未声称运行时校验已实现。

## 对抗收益对照与双通道改进（2026-10-22）

证据见`output/evaluation/critic-value/测试总结.md`。A判断优先、B独立首读、C首读+结构化反证各2次，均检出6条人为构造错误且未误伤6条合理判断；C2对一条原始肯定的关联强度给unknown，其余原始摘录保留。只证明在该简单样本上能核查证据边界；未证明首读/强化提示优于普通复核，不能证明审美增益或无同质盲点。生产生图维持暂停。

对抗每岗位改为两通道，仍不打分：

1. **独立漏项**：不看评分，先审完整材料，列任务、整组比较与本职关键风险，保存证据及摘要。不能只等评分团提出肯定句；允许0问题。
2. **断言核验与覆盖映射**：领取完整本职评分（含限制条件），核验肯定事实/假设/效果范围；把首读风险映射到原issues和limits，区分已覆盖、新增有据、范围澄清和任务外。仅真正未覆盖且影响当前门槛的有效问题计入增益。
3. **独立总监裁定**：保留同岗位评分/对抗配对；总监裁定而不改分。新增批评要有反证并经采纳；“更尖锐”“更多条”不是目标。当前未授权删减用户要求的角色配置，也不因0新增自动停用。
4. **模型替换校准**：未来同题异构模型与人工标定边界样本，对比完整双团和同预算普通复核；当前未执行，不声称跨模型可靠。独立上下文只隔离讨论历史，不消除同模型共同偏差。

流程收益分开统计：合成错误检出/合理判断误伤、原稿新增有效阻断、范围澄清、争议待核、修改后改善。主张“品牌关联明确”须注明字面、策略依据或实测感知，不含品牌字不自动判无关联；没有实测不把传播潜力写成效果已验证。

探索性漏项试运行D补记：4条首读意见经完整原报告映射为2已覆盖、1范围澄清、1任务外，0新增有据阻断。双通道已做一次试运行，但未证实比原机制增加真实缺陷检出。A条件是判断优先的基础对抗，不是重新执行评分团，因此同预算二次普通评分比较仍未做。不得将本轮结果写成已证明完整对抗团比普通复核更好或无用。
