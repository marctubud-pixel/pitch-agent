# 评估方法与裁判协议 v1

2026-10-21，工作台内部试行规则。用于文案主题、实际KV、单页排版和整套提案评审；首次使用及更换裁判模型时须先校准。详细来源与项目原尺度见 [六项目方法索引](../../output/evaluation-research/README.md)。本协议采用公开方法的任务化改编，不等于安装或运行其官方评分模型。

## 1. 调用位置与结束条件

| 时点 | 执行人 | 实际输入 | 必须交出的结果 |
| --- | --- | --- | --- |
| 策略正文完成 | 独立品牌负责人视角 | 策略、证据链、核心任务 | 品牌立场、过渡、论证与结论审校；此处不派用户裁判 |
| 主题创作完成 | 文案/品牌/用户/传播独立裁判 | 已确认任务、匿名三案文字 | 每案主张诊断及三案差异；先内部改好再提交用户 |
| 美术定向完成 | 视觉总监 | 确认主题、品牌历史、质量参考 | 每案检查卡、三案预期差异；视觉总监内部选定冻结参考 |
| 实际图生成后 | 独立视觉/品牌/用户/传播裁判，文案核图文 | 两阶段输入包，见下 | 单案报告、实际缺陷定位、明确结论 |
| 单案报告齐全 | 视觉总监总览，再由独立视觉及传播裁判验收 | 同版三图、成对图、质量参考 | 整组差异报告及去偏复核；可全部退回 |
| 提案排版完成 | 排版执行自检，独立视觉与品牌终审 | 实际页面截图、整套缩略、来源 | 页型主角/阅读顺序/整套节奏通过；KV另保留自身结论 |

完成依据是报告齐全且阻断闭合，不是岗位名齐全或平均分足够。图片、单页、整套、文案分别保存结论。

## 2. 先冻结评审包

总控按 [评审包模板](../evaluation/review-packet.template.json) 填写：版本/哈希、交付层级、目标人群与购买角色、核心问题、主张和原文案、任务必需点、品牌素材、同类案例、按用户授权由视觉总监选定冻结的质量参考、3方向职责、关键限制和已知缺口。每个创意关键点写成可看见的命题并分清关键/辅助；可记录位置、比例区间与来源，但不发明统一产品占比。

实际图片和参考均记录可访问路径与阅读分辨率。全幅看构图，原图/局部看文字、瓶身和材质；截图外框不为画面本身加分。代码检查只负责溢出、加载等技术事实。

冻结版包给创作者与裁判同一标准。确需改规则时另建版本、说明用户/证据依据，并重评受影响项；评分后不能因作品失分放宽规则。

完整评审包由总控保管。实际派发时另存首读脱敏子包，只含匿名实图/文字和中性问题；第一阶段裁判不得拿到完整JSON、主题字段、方向职责或核验包链接。首读保存后再发第二阶段子包。模板中的阶段字段描述的是派发计划，不构成自动访问隔离；当前由总控手动分文件与分次派发。

## 3. 两阶段读图

**第一阶段：无作者解释首读。**新上下文仅提供匿名实图和中性问题：画面是什么、什么节点、哪个品牌/产品、核心意思、最强视觉记忆是什么、哪些地方不确定。此处不给方向标签、创意说明、推荐、旧分数或别人的意见。裁判记录实际看到的线索与误读，保存后才进入第二阶段。模型首读不是测得真实三秒注意力。

**第二阶段：任务与参考核验。**补发任务卡、主题、关键点、真实品牌素材和质量参考。逐点记录 `visible / contradicted / uncertain`，附画面位置与依据；辅助点可加 `not_applicable` 并说明原因。关键点 `uncertain` 时需补图或补证，不能由作者解释当作已兑现。补发后不重写第一阶段结果。

同一裁判可按顺序接收两阶段；已参与创作或读过方案者标为复核，首次盲读另派新上下文。不同岗位隔离不等于不同底层模型，二者分别记录。

中文文字单独逐字核验：保留Unicode汉字、数字及品牌/SKU符号，把图片转写与冻结原文对照，逐项记录增、漏、错与位置。可说明空格/标点的允许差异，但保留原文和原始转写。OCR与看图互核，争议看局部原图；小字辨不清标为未核验，不把OCR猜测或删除汉字后的匹配当通过。

## 4. 视觉裁判检查法

按下列顺序检查，重叠项目归入同一问题ID，避免一处缺陷被重复累计：

1. **整体质量诊断（借 PosterReward）**：基础视觉、AI结构/物理伪影、文字准确、需求兑现、独立美术表现。它们分别判断，不能因清楚无错而默认好看。
2. **创意兑现（借 PosterIQ）**：第一阶段读到了什么；第二阶段关键点实际出现了什么。寓意存在于说明中而图中不可见，要记录差距。关键点覆盖比例只是描述，关键缺失不被其他点抵消。
3. **审美顺序（借 aesthetic-foundations）**：焦点 → 缩略/大色块 → 明度 → 负空间 → 裁切减法 → 明确参考对照 → 3—5条修改。要声称做过灰度或模糊检查，须有实际显示/诊断图记录；脑中估计另标。每条参考只评价明确关系，不要求复制整张图。
4. **缺陷定位（借 AesEval 与 PRISM）**：布局看平衡、层级、留白、对齐；字体看字形识读和文字层级；图形看质量与相关性；色彩看和谐、对比、吸引及情绪适配。再核主题一致、可读、对比、对齐、遮挡。问题必须定位到元素ID、文字片段或区域，说明有意的破格/遮挡是否真的妨碍目标。
5. **品牌主KV专项门槛**：执行 [主KV规范](主KV视觉总监与横向评审规范.md) 的统领性、节点专属性、品牌延续、产品融入、成组差异与精修质感。春节符号须参与创意；基准研究没有内置这些标准。

### 质量维度与内部尺度

视觉报告分别给构图层次、风格色彩、光线材质细节、产品/品牌融入、字图关系五项内部评分。所选质量参考须为相同交付水平，不能用草图参考支撑“精修”。其它岗位按自身维度评价，尺度解释一致：

| 内部分数 | 必须说明的依据 |
| --- | --- |
| 1 | 严重不成立，核心意思/身份/结构有明显错误 |
| 2 | 有想法，执行有重大差距，需要改定向或结构 |
| 3 | 意思可讲清，但完成度低于已确认的本阶段参考 |
| 4 | 达到本阶段参考和任务标准；逐项指出兑现位置，可有非关键优化点 |
| 5 | 在指定关系上优于基准且仍符合任务；写明具体优点和取舍 |

这是项目新建的 **1—5内部试行量表**，不是六项目原生分数。试行通过条件：关键门槛成立、适用必评维度均至少4、必需角色分别明确通过、整组检查通过。未能检查的必需项为待核验；不以空值、均值或最高分通过。用户/传播分是模型模拟判断，不转换为满意率或效果概率。

## 5. 视觉总监的整组三案检查

先每张独立，再 A/B/C 同屏，最后两两比较。隐藏作者推荐，交换 A/B 等展示顺序，允许相同、各有取舍或全部不合格。

每对记录核心符号/隐喻、构图骨架、空间场景、美术材质、产品参与方式、春节表达的具体异同。构图相近不必然失败；但核心机制和产品关系相同、只换人物/文案/道具，必须退回。共享品牌色不是重复罪证，也不能成为差异证据。

同时做节点替换、竞品换瓶、主题互换检验，指出是否仍成立以及原因。A稳健案对照历史品牌春节主KV；B突破案对照任务约束；C推荐案对照已核验证据和推导，不把推荐身份作为高分理由。专项缺陷按阻断处理，独立视觉及传播裁判出整组结论。

## 6. 文案裁判分支（借 copy-that-sells）

先判问题在主张、结构还是措辞；依次检查主张清楚、人群/时刻明确、承诺/情感具体、事实有据、语言顺畅。再做品牌署名替换、主张直白复述、主题压缩、图文互补和三案互换检查。创意说明不能代替广告自身表达。

文案总监仍先锁主张和主题，再由美术展开；生成后回查图文共同表达。主张正确但画面弱时主要退回美术，不擅自推翻已确认的主题。

内部文案评分分开记录：主张清晰、品牌关联、受众情感、语言节奏、差异与图文可执行性。4U仅作为问题表：受众价值、节点相关、品牌专属、具体感知。品牌KV不强制促销紧迫感、数字或CTA；促销任务另按真实优惠条件检查。英文词数、禁词脚本和Anti-AI分不能当中文创意验收。

品牌裁判检查品牌内核/资产与事实；用户模拟裁判检查能否理解及情感感知；传播裁判检查简明记忆、品牌力、用户体感、竞品差异和有据趋势。主题阶段四方均保留；策略正文仍仅品牌审校。没有原图时文案阶段的图文执行只作可行性判断，实际兑现留待视觉阶段。

## 7. 报告、修改与复评

执行 [裁判交接模板](../evaluation/裁判交接模板.md)，至少保存：角色、实际模型/未知、独立性、输入版本、实际看过的图与显示规格、方法及来源版本、首读、分项依据、问题位置、关键程度、修改动作、明确结论和范围。

结果用 `pass / revise / cannot_assess`；工具调用失败另记 `failed`。任何未知或调用失败均不等于无缺陷。上游reward、分类概率、内部1—5、关键点状态、IoU/accuracy分别保存原单位，不相加、不归一成统一百分制。没有真值的定位只记录区域，不算IoU。

总控合并同一问题，视觉/文案总监给修改方案。优先修核心机制，再修构图、材质/光线与细节。可修局部时明确修改范围与保留项；机制不成立时重定向。修改后复查原问题，并回归品牌、节点、产品、文字与三案差异；记录新问题。常规三轮及之后专项优化沿已确认规则执行，每版保留，旧稿仅在过程入口查看。

## 8. 方法运行与模型替换

方法可以先由独立Agent执行；官方PosterReward/PRISM权重、benchmark与检测脚本为另一种接入，状态单独记录。只有真的读取权重并获得输出，才填写官方模型分；本次均未运行。六个项目具体原尺度、源码差异、许可和部署要求见研究索引。

更换裁判模型前，用有用户判断的好/差/相近样本校准：文字判错、材质差距、品牌换瓶、春节替换、A/C重复等。用于讲解的例图和保留测试样本分开；记录误判与不确定，校准标准在跑前冻结。尚无足够样本时标“未校准”，保留人工确认，不能继承论文准确率。

校准记录须指向裁判配置、任务/语言范围、已锁参考、样本集及事先定义的判定标准。未校准裁判可出诊断与试评分，但评审结论最高为 `cannot_assess`，不能据此自动通过或提前结束。用户明确接受某稿可另存人工确认记录，不回填为模型校准或独立裁判通过。
