# 参考图评审试行规则 v2

来源：2026-10-22四轮小样本测试；仅参考用途审批，不替代草图与精修门槛。

# 参考评审规则 R2（实验修订，非生产验收）
## 对象与职责
评分对象=图片+明确用途，不是整张原作美不美，也不是未生成成稿。单张配色/材质辅助参考与整组创意方向分别审批。单图通过不授权精修。
每卡有类型：component（仅局部技法/配色材质）、direction（核心创意机制/构图整体）。component的评分仅适用它要解决的事情；不适用项标not_applicable，缺本阶段必需证据标unknown，不能混用null掩盖失败。
visual=可见美术质量与所借构图/材质；brand=所借元素与品牌的兼容及不允许搬来的身份；user=所借表达可读性/场景约束（模拟）；spread=指定比较范围内的重复风险与主记忆机制，不负责预测真实传播。
辅助材质的用户情感、整案记忆、市场新颖不适用；不得为此要求先画成稿。但应指出该材料后续会产生何种可读性风险。
direction必须有一句从参考方法到目标主题的转译假设。缺少时退回补卡，不要求先画草图。转译假设写清才可在草图验证是否兑现。component不需独自承担全部创意。
## 尺度和结论
1可见/已知事实直接反驳用途；2主要借用机制不成立；3有部分证据但本阶段还缺明确连接/执行限制；4该项所有必需检查有图或用途卡证据且无关键矛盾；5有指明的同类对照且在指定关系明确更优。unknown=null且需说明缺什么；not_applicable=null且需说明不属于此卡用途。
分数先证据后判断。图像观察、卡片事实、推断分别标注。图源低清导致局部未知，仅限制高精材质用途，不把低清证明美术差。
建议结论为pass_component（仅组件借鉴通过）、advance_sketch（完整方向准入）、revise_card（补转译/改范围）、reject_use（明确重复/冲突）、cannot_assess（关键证据不可用）。pass_component不代表整个参考组合通过。适用必评均>=4，无硬退、无本阶段关键unknown才准入；不取平均。
## 边界
四种创新是整组/核心方向的检查，至少一项有具体对照证据，不强制辅助材质创新。稳健案继承品牌语言不等于突破；与竞品相同整体构图不可因微改色彩而通过。只借通用材质不能自动视为抄整个竞品画面。没有全行业数据不能声称全市场独创、流行、效果。
品牌色/Logo/瓶体共存不是自动硬退；检查是否都被强作主体隐喻。节点元素数量不是机械扣分，检查是否形成竞争焦点。参考阶段记录风险；草图阶段核实际结果。

## R3冻结补充
固定本职维度：visual={表现质量,所借构图适用性}; brand={品牌兼容,主题转译}; user={借鉴机制可理解,场景转译可行}; spread={记忆机制清楚,指定对照差异}。component只借材质/色彩时：visual表现质量、brand品牌兼容、user借鉴机制可理解适用；其余不适用。spread两项可均N/A，但必须审查明确禁止整体复制、未声称效果/热度的边界；只可签boundary_clear不是全项通过。整组仍需主参考，不能靠全组件pass通过方向。
方向卡必须写可检验转译句（参考方法→目标载体→主题/品牌关系）、比较对象和至少一种具体创新假设。参考阶段评价假设的证据与可验证性，草图阶段才评兑现；不可把假设当已实现。视觉负责美术/构图/视角的差异依据，品牌核转译，传播核声明范围，提案总监仅合并不改分。
硬退单列hard_reject:[{rule,evidence}]，不能因为硬退降低无关维度的美术质量/可读性。结论优先级：有证据硬退reject_use；已知卡片缺项revise_card；本阶段关键外部证据不足cannot_assess；其余依适用分数决定。已知必填缺项：相关维度3分；外部看不到/取不到：unknown；职责/用途不适用：not_applicable。一项问题只记一个ID，不重复扣罚。
若本职全部N/A，可给boundary_clear（仅无越界），不能捏造4分，也不单独批准参考组合。每次候选清单的分数/门槛与自身排序无关，先单卡后跨卡。历史图片身份仅按卡片给定样本，不证明当前趋势。

## R4硬退优先级修复
H1：所借整体结构与指定竞品相同，只换产品/文案/颜色，且用途声称创新，reject_use。
H2：所借整体结构与同品牌同场景历史图相同，只换文案/颜色，且用途声称构图或视角创新，reject_use。H2与H1同级。
卡片缺转译句只能在没有H1/H2等直接反证时给revise_card；不能用补卡掩盖已知重复。先列hard_reject再算最终decision。独立表现质量不受硬退扣分。
参考创新为本轮约定比较范围内的可执行假设，不宣称全市场独创。direction若仅缺转译句而没有直接复制证据，相关维度3，revise_card。

## 测试后的执行限制
传播记忆分在逆序新上下文出现3/4漂移，暂不单独用于自动放行；争议需复核而非平均。尚无核心方向正例全覆盖，整组进入草图/精修仍必须满足完整包检查。测试详见output/evaluation/reference-trials/测试总结.md。
