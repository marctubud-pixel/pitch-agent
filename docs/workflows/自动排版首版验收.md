# 自动排版首版验收

日期 2026-10-24。用户指定pstack poteto-mode作为本轮开发方法。已读取本机0.9.102技能并执行，未修改hooks信任设置。开发方法与品牌研究、创意评审业务流程分开。

## 已实现

结构化内容台账、品牌配置和资产清单进入本地排版器，输出PPT、PNG预览、选择记录与来源备注。页面先按任务选择文字主角、案例主角、作品主角或逻辑关系。字体测量决定换行和可容纳字号，保留原文；超量重复案例分页，不能容纳的段落报错。

三套构图语法分别为留白编辑、品牌剧场与观点叙事。品牌色来自同一配置，构图、文字尺度、案例容量和节奏不同。深色品牌剧场每页两张案例，其他两版每页最多四张。同一内容输出29、34、29页，原26页内容顺序保持，每版追加三张应用示意页。

全部六份用户PDF共516页已有全页缩略索引，另放大复核6页；未声称每页都逐字核验或量出精确字号。16张静态参考及动态抽帧已交叉核查。目录在 `output/auto-layout/research`。自动布局参数是从参考提炼的本项目规则，不冒称原作精确测量值。

本地网页支持风格选择、配色与普通文案编辑、启动生成、翻页与下载。当前界面仍使用梦之蓝样本的固定证据和资产，品牌名修改只影响提案页眉，不能自动替换图片中的品牌。其他同结构项目通过命令行清单接入。

## 可编辑范围

提案标题、正文、注释和逻辑圆形都是原生PPT对象。案例图、创意海报是独立图片对象。用户要求的海报文字已在原图内，不拆为PPT叠字，海报页在网页中锁定文字编辑。应用页的场景底图与海报是两个独立对象，可整体替换海报。

首版mockup为正面平面开窗，按用途与比例校验。本轮使用一个imagegen生成的户外灯箱底图，配浅色衬边，明确是示意而非真实投放。手机、电梯及包装场景需要相应资产清单。透视、遮挡、包装3D和材质渲染尚未自动实现。

## 评审与修复

两位独立架构候选及交叉评审选择有限模板方案，保留来源、原文及输入校验，未引入通用布局语言。输入和导出两个模块隔离委派。独立行为测试36项，独立缺陷回归11项均通过。

实际渲染审查发现三圈没有共同交集、深色辅助案例过小，修正为真正三圆交集及两图分页。审查中对编辑版第2页拥挤的意见经主审与最终独立审查实看驳回，未机械修改。评分不取代可核验问题证据。

代码评审发现品牌名不生效、海报文字假编辑、items额外列静默丢弃、对比图次序写死。已修复并添加回归。旧记录保留，不改写原分或历史结论。

三份最终PPT通过文件结构、几何与导出回读。另用LibreOffice独立渲染，逐页中文字符完整且使用PingFangSC，无替代方框。未进行Microsoft PowerPoint实机编辑验证，不能据此宣称全Office兼容。自动检查也不是用户审美批准。

浏览器实际点击生成完成一份29页新版本，并验证风格切换与预览。截图 `output/auto-layout/checks/workbench.png`。决策日志 `.audit/auto-layout.tsv`，最终独立审计 `output/auto-layout/checks/final-audit.md`。
