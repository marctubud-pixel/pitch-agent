# 视觉评审平均分准入 v1（试行）

2026-10-23 用户确认并要求记录。适用于后续出图的内部视觉评审；不追改历史实验分数，不代表已经实现自动执行，也不单独构成恢复生图的指令。参考图组件适用性、文案评审及其他阶段规则不因本文件自动改用平均分。

## 计算与通过

每位事先指定的独立评分裁判，对同一版本视觉稿给出一个1—5星整体分 s_i，同时保留形式完成度、表达价值、创意贡献及具体依据。维度用于解释，不再重复计入总分。

评审团得分 S = (s_1 + s_2 + … + s_N) / N。

- 所有计分裁判等权，每位一个整体分；角色名单在看稿前固定，不按结果增删票数。
- S ≥ 4.0：达到试行分数通过线；S < 4.0：修改。
- S ≥ 4.5：更优目标，不是必需门槛。无需强求每位都给4或5；分歧原样保留。
- 用未四舍五入的实际平均值判定。展示可保留两位小数，3.99不得显示取整后放行。
- 例：4、4、3、5，平均4.0，达到分数线；4、4、3、4，平均3.75，退修；4、4、5、5，平均4.5，达到更优目标。
- 缺评、关键证据不足等无法形成整体分时，先标记待补评，不通过缩小分母或默认填4放行。重试不作为新增票；修改稿按新版本重新评审，旧记录保留。

本规则替代后续出图评审中“所有角色/每一分项必须≥4”的数值门槛；不取消下面的硬性问题处理。

## 有据硬性问题

任何评审或对抗审查发现明确的产品/品类误读、创意妨碍核心传达、违反已确认Brief，须注明画面位置、证据及影响，提交总监核查。若成立，退修，不能被平均分抵消；尚有关键争议或证据缺失则待核查，不默认为无问题。

含蓄、另类、局部美术不够精细或个人风格偏好不自动构成硬退。产品向与品牌向按各自任务核查，不要求所有品牌画面都展示产品功能。

总监整合意见、核查争议并组织修改，不直接改裁判原分。对抗团仍只提有据批评，不计入平均分。评分裁判不参与该稿创作；独立上下文不等于真实品牌方/消费者或跨模型验证。通过仅代表内部模拟评审通过。

## 后续校准与版本

当前阈值是用户接受现有误差后的工作标准。104张最新用户复评对照中，封存AI整体预测MAE约0.971星；该值不是加减修正量、单图误差保证或通过置信区间。

后续扩大图源时，兼顾国内外、用途、品类、不同美术风格和低中高水平，补入用户真实认可的高质量基准。样本不足是可能因素之一，尚未证实是唯一原因；用途假设、模型共同偏差与评审标准也需继续检验。

新增资料先保存模型预测，再收集用户评分；校准样本与验证样本分开，避免在已知反馈上反复调参制造改善。继续报告同用途排序、严重分歧、重复稳定性与评语证据覆盖，不只看平均分差。

图库扩大不自动抬高分数或通过线。依据新证据更新基准图、评分描述或阈值时，记录新版本、变更理由和对照结果；阈值改变需用户确认。原图、用户历次评分、裁判原分和历史规则保留。
