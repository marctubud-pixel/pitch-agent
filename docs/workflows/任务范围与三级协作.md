# 任务范围与三级协作

2026-10-24。用户确认执行计划，新增以下业务约定。通用调度、范围校验、审校门禁尚待开发，不以文档更新证明功能上线。历史评分保留，具体项目的绘制授权不因本次更新扩大。

## 统一资料比较口径

调研负责人在任务卡中明确传播目的、交付类型、主KV或子海报、品牌或产品导向、节点、SKU、年份窗口、人群及纳入排除条件。每个搜集者使用相同范围版本。重大范围改变回到任务卡确认。

品牌春节主KV任务的直接比较集合采用同用途春节品牌主KV。春晚赞助、活动现场、促销物料、场景子海报、视频截图不自动算同类案例。场景构图本身不是排除理由，判断的是传播用途和作品身份；春晚项目里的图片若能核实为春节品牌主KV仍可纳入。

每条案例记录来源、品牌、SKU适用性、年份、传播用途、主KV身份依据、任务关系和核验状态。分为直接比较、补充背景、视觉借鉴、待核验四类。背景资料可解释品牌动作，但不计入同类样本；视觉借鉴不充当用户偏好或趋势证据。身份未核实者不进入同类比较。找不到时报告缺口，不用其他用途凑数。结论绑定合格样本及其适用局限。

## 参考图按视觉问题搜索

视觉负责人为每个方向建立搜索卡，记录已确认主题版本、核心主张、品牌表达、节点依据、画面主角、要解决的视觉问题、与另两案的差异、检索词、排除条件。

按需要分派构图视角、美术材质、创意载体、产品融合、场景情绪等搜索任务。候选记录具体借鉴位置、如何转译、缺失部分及禁止照搬内容。允许跨行业；局部参考不要求满足整案所有属性。

汇总去重后，按同一搜索卡先评适配性再比较质量，保留主参考、辅助、备用及淘汰理由。高美术分不能抵消不适配。组合需覆盖关键要求，不堆砌矛盾风格。沿用多候选、独立评分、对抗及三方向横向比较，遵守自动或辅助模式的确认约定。

## 措辞通过后正式排版

保留早期策略审校，增加整稿文案冻结节点。顺序为内容证据汇总、措辞优化、独立品牌策略审校、冻结版本、正式排版、实际渲染复核。

文案负责人统一标题、正文、品牌到竞品等转场、术语、创意说明和结论。以为品牌解决问题的立场表述，减少长段与空泛形容词。模型和术语须帮助判断，不以数量衡量专业性。润色不得编造事实、去掉限定条件或把相关性写成因果。

策略负责人对证据及推导负责，逻辑缺口退回策略，不用措辞掩盖。策略正文和整稿措辞由独立品牌策略审校者复核；Slogan保留文案、品牌、用户和传播评审机制。

排版输入包含审校记录、版本号、各页目的、核心句、辅助说明、证据ID、图片ID及可拆页范围。允许拆页，不擅改主张或删除证据。需要改文时退回文案，重新核验受影响内容。早期样章可验证容量，正式整套排版在文案通过后执行。上游版本改变时关联页面旧验收失效。

## 三级生产与独立评审

一级提案总监负责问题聚焦、任务拆解、负责人指派、依赖顺序、预算与停止条件、阶段交接和最终全案复核。总览检查原问题是否被回答、证据与结论是否相扣、三个方向是否有差异、主题画面是否一致、文风版式及交付是否完整。

| 二级负责人 | 三级执行任务示例 | 必交产物 |
| --- | --- | --- |
| 调研负责人 | 品牌历史、同用途竞品、用户场景、报告检索、来源核验 | 范围卡、分层证据及缺口 |
| 策略负责人 | 分线判断、三圈交集、推导及结论 | 有依据的策略链和切口 |
| 文案负责人 | Slogan、标题正文、转场、创意说明、措辞编辑 | 候选文案及审校版本 |
| 视觉负责人 | 分方向搜图、草图、授权范围内绘制、mockup | 搜索卡、候选及转译、图像版本 |
| 排版负责人 | 页型、图表图墙、品牌适配、PPT导出及检查 | 页面方案、PPT和验收记录 |

独立评分、对抗及审校角色在创作链之外，不参与被审稿创作。生产负责人不能自签独立通过。独立裁定保留原票，采纳或驳回需证据，生产总监不能豁免硬性问题。裁判接收必要Brief和实际稿件，不接收作者推荐、旧分和其他裁判结论。模拟评审不代表真实客户或消费者测试。

每个委派任务记录任务ID、父级ID、范围版本、输入版本、负责人、输出、完成条件、评审对象、失败退回位置、预算或轮次上限。共享输入只读，执行者独立写产物，由负责人合并去重。模型按岗位能力配置，三级是责任分工，不要求固定开启所有岗位；只并行处理依赖已满足的任务。

## 后续开发和验证顺序

### 自动与辅助模式的人工决定

自动模式在约定授权、预算和评审规则内执行。辅助模式按模块勾选人工节点，至少可分别配置策略、文案、视觉、全案内容审核、最终交付审核。视觉节点可细分为参考、草图和成稿。到达已勾选节点时等待明确回复，超时不等于同意。人可提交观点、主题或参考及借鉴意图，作为带来源的正式候选进入对应负责人复核。

用户对创意、审美、策略取舍拥有最终决定权。选择与AI意见不同时保留异议并记录“用户指定采用”，不伪装成“评审通过”。事实错误、来源缺失及其他非偏好硬性问题仍明确标记，用户选择不能修改事实验证状态；需要补证、纠错或移除不成立断言。模式变更须记录，不能倒写确认。

全案审核分两轮。调研、策略、文案、视觉完成后先审完整内容与表达，包括推导、图文关系、措辞和衔接；通过或完成合法人工取舍后冻结内容，再进行正式排版。排版后再审包含布局、实际渲染、完整性与可编辑性的最终交付。两轮可分别配置人工参与，不合并为含义不清的单一“全案确认”。

### 已确认的实施顺序

1. 排版跨案例验收。保留梦之蓝三风格，增加不同品牌或包装案例，验证内容长度、图片比例、品牌适配、mockup及实际PPT编辑渲染。不以导出成功代替审美通过。
2. 统一项目数据。关联任务、证据、推导、文案、图像、评审、页面及版本，同时接入范围分类、负责人和审校门禁。
3. 分段自动执行。依次接调研、策略、文案、参考草图、授权精绘、排版；实现模型接口、重试、费用记录及自动辅助模式。产品岗位与poteto开发协作分开。
4. 新Brief端到端验收。优先用不同品牌的包装任务验证迁移。静态稳定后再推进动画与云端。

待实现回归包括异用途混入、身份未知、参考精美但不适配、润色破坏事实、未审校请求排版、自创自审、输入变化仍复用旧通过。以上是验收规格，尚非已运行测试。
