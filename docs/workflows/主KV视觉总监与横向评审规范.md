# 主KV视觉总监与横向评审规范

状态：2026-10-21，依据用户对梦之蓝三张V0的反馈更新；是后续执行规范，不代表已完成新一轮评审或生图。适用于主KV；包装等交付需另定媒介标准。

## 1. 先确定交付层级

任务卡与美术定向必须写清主KV、场景子海报或其他用途。本次为通用春节品牌主KV：承载整场传播的核心主题、品牌识别与核心视觉，并能成为后续子海报的母体。不是把人群生活片段配上产品即算完成。主KV可以有人物，但人物不能让品牌核心视觉退化为通用生活方式照片中的摆瓶。主KV也不等于瓶子无限放大。

## 2. 视觉总监的职责

生成前：核对主题、交付层级、历史品牌春节美术、真实品牌资产与质量参考，明确每方向的核心视觉装置、构图骨架、材质、光线、产品关系、春节表达以及不可采用的相似做法。
生成后：同时看三张实图，既检查单案，也检查整体选择是否有意义。不能把全部责任外包给单图裁判。制作整组缩略对照，再逐张放大检查。视觉总监组织修改，不签发自己的独立通过。

## 3. 必须检查的六项

| 项目 | 可观察证据与退回条件 |
| --- | --- |
| 主KV统领性 | 是否有一个可记忆、可延展的品牌核心视觉；如只能讲某个家庭人物的小故事、替换场景便失去整体概念，退回美术定向。 |
| 春节专属性 | 暂时遮住主题中的春节文字，观察核心器物、仪式、时间寓意与构成如何共同建立春节。做中秋/普通家宴/一般致谢的替换测试；若只改文案、移走福字仍完全成立，须加强。窗花、灯笼、纸雕等是可选语言，不是必备堆料清单；春节符号须参与核心创意。通用春节不使用未确认年份或生肖。 |
| 品牌延续与专属性 | A稳健案必须与真实往年品牌春节主KV并排，明确延续的美术语言和改善之处；不能只沿用蓝金色。各案除瓶体、标识外，核心构成须与品牌或产品有可解释联系。检验换成竞品瓶后是否仍原样成立。借品牌曲线/轮廓时先核验真实资产，不凭印象仿造Logo。 |
| 三案视觉差异 | A/B、A/C、B/C逐对比较：核心视觉机制、构图、空间、材质/美术手法、产品参与方式。三案可以共享VI，但不能仅换人物、文案、道具。若缩略看是同一构图套路，且品牌与场景关系相同，整组退回，即使各单图得分高。 |
| 产品有机融入 | 产品与核心视觉存在造型、空间或寓意上的联系，并具有合理尺度、光线、接触阴影、反射和遮挡。把产品移走后装置仍完全自洽且品牌意义不变，需解释其不可替代作用。大瓶不等于融入，背景贴Logo也不等于品牌化。 |
| 完稿质感 | 与明确质量参考在相近显示尺寸下比对构图、纸/金属/玻璃的区别、光线层次、反射、边缘、前后景、字体、标签与细节。泛光、金色或高清分辨率不能自动等于高级。清楚区分创意草图、提案精修视觉与印刷生产稿；本次仍须达到精修提案水准，不能以非印刷稿为粗糙开脱。 |

## 4. 三方向职责不变，表现方式重定

A：品牌延续/稳健微创新。先建立历史春节主KV美术依据，继承成熟视觉语言，再放大主题与产品特征。
B：突破探索。保留“新岁启程”的寓意；若采用纸路，需解决材料完成度、春节身份、品牌造型关联，不预先认定纸路是最佳方案。
C：依据推导的推荐。保留“为家奔忙的付出被看见”的寓意，将其提升为春节品牌主视觉，避免重复A的室内人物加桌前摆瓶构图。

用户认可寓意。按最新授权，视觉总监内部选择并冻结新美术路线与参考，直接生图；独立评审及整组总览过关后提交用户，无需另发参考确认。

## 5. 评审顺序和记录

1. 先冻结交付标准与参考组；缺少品牌身份/质量参考时标为缺口，不能用生活场景参考代替主KV质量基准。
2. 独立视觉裁判看每张实图、真实品牌资产和质量参考；独立品牌裁判检查任务、品牌延续与专属性；用户模拟裁判检查感知；传播裁判检查简明记忆、品牌力、情感、差异与趋势依据。图文仍需对应文案核对。
3. 先单图无解释阅读，记录第一感知，再提供创意说明和参考做专业比对。先前已参与的裁判不得冒称首次盲评。
4. 视觉总监总览三案；独立视觉及传播裁判另做整组横向复核。单案通过不自动推出整组通过。
5. 每项须有实际画面位置、对照依据、问题级别、修改动作。评分只是汇总；任一明确关键退回项不能被平均分抵消。后续统一评分尺度须在评审前明确，不追认旧分数为新标准通过。
6. 常规/专项迭代沿现有规则执行。旧图、原意见、修改与版本保留；未解决阻断不允许提前结束。模拟传播潜力不等于实际传播验证。
