# 研究方法与图表表达

## 当前露玛案例：先展示具体研究结果

用户进一步明确要看到调研数据、图表与参考。露玛默认正文现由五个结果板块组成：行业与市场、人群细分、竞品分析、产品与包装、突破口。行业图使用带年份和口径的公开数值；人群图明确相邻年龄证据与案例需求情境的区别；竞品按实际SKU的容量、标示酒精度和页面标价比较；包装使用已检查商品图；突破口由明确前提推导，并保留三个待验证方向。

本案例以英国零售为范围设定，品牌虚构，市场与商品资料来自公开出处，没有露玛消费者访问或问卷。当前未接通任意项目的自动研究执行。报告按独立身份保存为源码内只读案例包，不写入或冒充旧Artifact结果，也不继承旧核验通过状态。报告、精确数据与来源见[完整研究内容](../../output/luma-research-report-20261109/RESEARCH.md)及[数据账本](../../output/luma-research-report-20261109/RESEARCH-DATA.json)。

旧版“首条论点→首条缺口”的拼接不作为这个案例的洞察，核验状态矩阵也不代替竞品分析。原始记录保留在页面底部的既有研究区，历史来源与深链不删除。以下记录的是原方法框架及图表约定，不能用它取代当前具体结果。

将用户提供的 Dot 研究方法用于提案工作台的研究阶段：行业与人群、竞争与替代、产品与视觉三个视角并列整理，再汇合为机会假设。图表用于解释有依据的判断、比较和缺口，不替代来源核验。

本轮实现位于独立本地前端；入口为 `http://127.0.0.1:4415/preview.html#/p/luma/proposal/research`。真实联网研究、模型编排与业务运行时尚未接入，现有模拟核验不代表真实市场、客户或消费者批准。压缩包仅作为参考读取，未执行其中脚本或访问其私有服务。

## 研究内容和图表

| 视角 | 要回答的问题 | 适合的图表及前提 |
| --- | --- | --- |
| 行业与人群 | 行业及场景变化、需求、受众和文化条件 | 市场范围圆、趋势图、人群气泡图及构成条形图；必须有明确单位、口径、时间和来源 |
| 竞争与替代 | 谁满足相同需求、利益和差异如何表达 | 竞品定位图、能力矩阵及比较条形图；定位坐标必须有定义及可追溯依据 |
| 产品与视觉 | 品牌条件、信息识别、产品限制；包装关注货架、材质和工艺，主视觉关注媒介、距离和主张 | 视觉色彩比较、信息或证据矩阵；简报条件与实际研究发现分开 |
| 综合 | 已支持观察中的张力、可验证的机会 | 观察→张力→机会假设链、风险矩阵；最终定位、取舍与行动在策略阶段形成 |

每项发现显示当前判断、依据、对设计的意义及限制。未取得证据时显示待补问题；未知不按零值绘图，缺证不显示为已证实观察。

当前 Luma 的本地演示记录只提供走查样本及既有论点，因此默认展示样本条形图、证据矩阵和洞察链三类图。4家样本、2家独立陈列是虚构工程走查记录中的统计，不能解释为市场份额。没有数据的行业规模、支付意愿、竞品位置等保留缺口。

另有主动展开的独立工程示例，展示上述9类图表：市场范围、趋势、气泡、条形、定位、矩阵、配色、风险、洞察链。所有对象和数值均为虚构，不进入项目证据、机会假设、核验或放行；更换项目或报告后重新收起。各图提供对应文字数据表，必要内容不依赖悬停。

## 版本与来源

`Artifact.researchMethodPlan` 是可选的版本化问题计划，只在既有本地研究生成命令创建新报告时记录。计划绑定项目、报告ID/版号和实际简报快照，记录 A/B/D→C 的依赖；不表示已执行三个智能体，也不保存伪造的进度、结果或评分。

已有报告不补写计划、不迁移或重置数据库。只读页面从报告所用的历史简报解释任务条件；当前简报仅用于提示过期。重新生成后使用新报告和新简报，旧报告的计划保持不变。有效的已保存问题以该版记录为准，不被新模板覆盖。演示翻译按绑定简报身份选择，保留用户填写的原文。

论点访问优先完整ID，兼容简写仅限既有 `cN` 格式，并限定当前报告的真实论点和来源。显示为已支持观察还要求引用完整、来源有效且核验未过期；图表不会改变门禁。既有研究板、案例、原报告及焦点链接保留在折叠区。
