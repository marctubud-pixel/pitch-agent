# 使用提案工作台

规范版本：1.4.0。当前应用是中文桌面工作台，提供本地模拟和绑定稿件与输入身份的案例展示；这不表示生产账号已接通。正式自动业务、真实协作账号及部分服务仍待接通。

## 本地简报服务

默认入口展示本地模拟及青屿案例。开发者按[简报HTTP启动说明](../development/http-brief.md)切换后，可在独立SQLite中新建、读取、保存和确认简报；刷新与服务重启读取同一存储。作者显示真实本地操作人；还可登记来源和读取研究原件，未接阶段保持空态。原Brief附件只保留文本及元数据，品牌PDF原件已迁入此HTTP入口，其他格式及模型采用仍待接；旧输入模块和Mock本地文件保存保留。默认不执行模型，显式研究配置的受限执行见[研究接续](../development/seven-stage-research.md)，不提供生产账号。

## 从任务到交付

1. 在首页打开项目，或新建提案，输入Brief、附件及品牌资料。核对项目名称、提案类型、品牌或产品、背景、目标受众与交付内容；未提供的事实保持未知。
2. 在简报与任务页修改同一任务卡，有权限的人确认。实质更新形成待确认新版，右侧查看意见和版本；进入下一页只是导航。
3. 研究页先看四维结论、图表与原图，详细来源和核验展开查看。关键依据不足保持研究待补，已有结论仍可阅读和下载。
4. 策略页查看研究结论、方向交叉点和发力点，说明为什么选这条方向。具体主题和画面由后续阶段展开。
5. 文案与主题页比较三个实质不同方向，查看主副文、推导与推荐；详细原评、质疑和改稿展开。推荐不等于人类选定。
6. 视觉页按方向查看实际参考、草图、当前稿与样机，区分试稿、待评和阶段准入。人类视觉负责人、视觉Agent和独立裁判分别标识。
7. 版式页阅读整案，使用翻页、目录、缩略与全屏；预览和导出共用同一Deck。终审与交付页先看成稿，再看可定位问题及范围，最后处理实际交付。

前台共七阶段，版式之后保留终审。独立内容审阅已退役，旧记录只读保留，阶段衔接由比稿Agent持续检查。

## 查看当前青屿案例

进入青屿项目的终审与交付，可阅读23页本地稿和已有独立诊断，按建议页码定位、展开依据并下载演练PPTX。当前研究仍待补，图像是生成试稿；本地诊断没有签正式业务、审美或人类批准。

成稿预览、正式状态、终审诊断、已下载文件和正式交付分别显示。正式layout数据为空时仍按正式状态等待，不因看到了本地稿而改成完成。

## 协作与保存

右上工具呈现人类成员和角色，阶段想法与版本在右侧。游客只读；本地角色演示不代表真实线上账号授权。意见绑定实际对象和版本，没有落实就不能写已更新。

遇到冲突或保存失败保留草稿并核版本；未知结果先对账。默认演示数据存于当前浏览器，换浏览器或清除存储可能丢失本地操作，Git版本不能恢复浏览器数据。在线PPT编辑、保存恢复和跨设备协作没有在本次工程导入中恢复。

辅助资料库、流程历史、交付中心和助手的完整专项交互仍待细化。当前可用与待接范围见[状态](../../status/current.md)，详细逐页合同见[页面基线](../pages/README.md)。

新协议、来源登记、受限研究与原件读取、方法绑定和缺能力时停止的具体范围见[接续说明](../development/seven-stage-research.md)。当前已接同版独立正文阅读、实际修订复查与研究声明/放行，详见[读者合同](../development/research-reader.md)。自动采集和后续生产仍未完成；默认不执行模型。

## 保存品牌PDF

本地HTTP新建页按实际能力接受PDF品牌资料，保留文件名和用途说明，创建后在Brief的更多信息/品牌资料区下载原件。上传可早于确认简报；不支持的格式在创建前提示，不把保存当作模型已读或人类采用。刷新出现待核对时核对原提交，不重新创建项目或换命令上传。具体范围见[原件说明](../development/brief-originals.md)。


## 处理独立读者问题

1. 确认简报后，展开研究页的**研究问题与独立读者**。
2. 保存要回答的问题及一至两位读者计划，再生成研究稿。
3. 打开读者报告，查看复述、未决、限制和原文依据。
4. 有需处理问题时，按原问题生成修订稿。
5. 逐项填写负责人处理，选择已核的新稿原段落，再保存回应。
6. 单独发起独立复查。未解问题继续保留，保存成功不代表解决。

回报丢失时核对页面保留的原提交。历史结果会明确提示历史，真正未知不会自动重试。研究还需事实、充分性、负责人接收及人工放行；策略后续尚未接通。默认无执行配置时不调用模型。[运行范围](../development/research-reader.md)与[实际核验](../development/research-reader-verification-20261111.md)分别记录。

## 查看品牌PDF文字

本地HTTP服务显式配置解析工具后，打开Brief的更多信息/品牌资料区，在对应资料下选择“解析这份PDF”。“查看已保存正文”按页显示提取文字，空页、加密、无文字或达到限制会如实标出；原件下载继续可用。缺工具时显示实际不可用原因，已有文字仍可查。

部分文字不等于全部内容已读，解析也不自动确认Brief或采用为研究依据。刷新出现待核对时核对原提交；未知结果不换命令重发。历史卡原件只读，显式本地重试保留旧失败记录。范围及配置见[解析说明](../development/brief-extraction.md)。
