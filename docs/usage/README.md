# 使用提案工作台

规范版本：1.2.1。当前应用是中文桌面工作台，提供本地模拟和绑定稿件与输入身份的案例展示；这不表示生产账号已接通。正式自动业务、真实协作账号及部分服务仍待接通。

## 本地简报服务

默认入口展示本地模拟及青屿案例。开发者按[简报HTTP启动说明](../development/http-brief.md)切换后，可在独立SQLite中新建、读取、保存和确认简报；刷新与服务重启读取同一存储。作者显示真实本地操作人；还可登记来源和读取研究原件，未接阶段保持空态。原Brief附件只保留文本及元数据，品牌原文件尚未迁入此HTTP入口，旧输入模块和本地文件保存已有实现。默认不执行模型，显式研究配置的受限执行见[研究接续](../development/seven-stage-research.md)，不提供生产账号。

## 从任务到交付

1. 在首页打开项目，或新建提案，输入Brief、附件及品牌资料。核对项目名称、提案类型、品牌或产品、背景、目标受众与交付内容；未提供的事实保持未知。
2. 在简报与任务页修改同一任务卡，有权限的人确认。实质更新形成待确认新版，右侧查看意见和版本；进入下一页只是导航。
3. 研究页先看四维结论、图表与原图，详细来源和核验展开查看。关键依据不足保持研究待补，已有结论仍可阅读和下载。
4. 策略页查看研究结论、方向交叉点和发力点，说明为什么选这条方向。具体主题和画面由后续阶段展开。
5. 文案与主题页比较三个实质不同方向，查看主副文、推导与推荐；详细原评、质疑和改稿展开。推荐不等于人类选定。
6. 视觉页按方向查看实际参考、草图、当前稿与样机，区分试稿、待评和阶段准入。人类视觉负责人、视觉Agent和独立裁判分别标识。
7. 版式页阅读整案，使用翻页、目录、缩略与全屏；预览和导出共用同一Deck。终审与交付页先看成稿，再看可定位问题及范围，最后处理实际交付。

前台共七阶段，版式之后保留终审。独立内容审阅已退役，旧记录只读保留，阶段衔接由比稿Agent持续检查。

## 查看当前青屿案例

进入青屿项目的终审与交付，可阅读23页本地稿和已有独立诊断，按建议页码定位、展开依据并下载演练PPTX。当前研究仍待补，图像是生成试稿；本地诊断没有签正式业务、审美或人类批准。

成稿预览、正式状态、终审诊断、已下载文件和正式交付分别显示。正式layout数据为空时仍按正式状态等待，不因看到了本地稿而改成完成。

## 协作与保存

右上工具呈现人类成员和角色，阶段想法与版本在右侧。游客只读；本地角色演示不代表真实线上账号授权。意见绑定实际对象和版本，没有落实就不能写已更新。

遇到冲突或保存失败保留草稿并核版本；未知结果先对账。默认演示数据存于当前浏览器，换浏览器或清除存储可能丢失本地操作，Git版本不能恢复浏览器数据。在线PPT编辑、保存恢复和跨设备协作没有在本次工程导入中恢复。

辅助资料库、流程历史、交付中心和助手的完整专项交互仍待细化。当前可用与待接范围见[状态](../../status/current.md)，详细逐页合同见[页面基线](../pages/README.md)。
