# 版式与整案排版 · 页面开发规格

规范版本：1.1.0。页面ID：`layout`。状态：已确认要求汇编；本次整理待核对。负责人见[layout-owner](../agents/layout-owner.md)。

这是页面显示、状态与交互合同；业务做法由岗位和方法承担，页面实现不自行改变业务门禁。共同视觉规则见[桌面UI基线](../specs/ui-system.md)。

## 使用任务

检查整案叙事和每一页实际效果，按目录定位并获得同版PPT。

## 结构

沿用版式工坊，主画布、翻页、目录／缩略、全屏、下载及必要协作；研究、策略、图文、样机沿用已认可图版。

## 交付语义

预览与导出同一Deck；页数按实际内容，23页是青屿演练。文字、图表、关系形状可编辑，像素图不假装可改内部文字。

## 状态

输入失配／资源缺失／生成中／导出失败／已有有效稿分开；不能用旧下载冒充本次新产物。排版后仍需终审。

## 已确认要求清单

- 按读者理解顺序、每页主旨选已有模板，研究与策略原图版可直接复用。
- 原文、原图、研究口径与身份沿用有效上游；改事实/主张退回负责人。
- 文字、图表、形状与图片分开，预览与导出消费同一Deck。

- 大幅图片、图文页、研究图版、策略关系图、比较与说明按内容选择。
- 图片等比，同屏比较保持尺度，页序与页码连续。
- 详细来源与过程放备注/附录，必要试稿与适用边界仍可见。

## 本页验收与接入核对

- 实际检查逐页图文、翻页/缩略/全屏/导出；UI检查与业务终审分开。
- 导出后核页数、原文、原图、来源与原生可编辑范围。
