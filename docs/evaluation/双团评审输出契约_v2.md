# 双团评审输出契约 v2（下一轮试行）

本文件补齐2026-10-22测试发现的契约空白；不覆盖旧报告、不代表运行时已实现校验。可替换模型须输出同一契约；格式不合格先修报告，不以自然语言出现“通过”触发下一阶段。

## 公共字段

schema_version、run_id、stage（reference/sketch/slogan/final）、role、model_id（未暴露则null）、packet_version、input_hashes、report_id。

## 评分

- items[].id：对应输入候选。
- scores[]：dimension_id、score（1—5或null）、status（scored/unknown/not_applicable）、required（布尔）、evidence、comparison_scope、comparison_ids。scored须有分；其余须null并说明原因。不适用需任务依据，不能用于规避必评项。
- positive_claims[]：id、text、evidence。
- issues[]：id、evidence、severity（blocker/major/minor）、blocking（布尔）、stage、suggested_action。
- hard_rejects[]：rule_id、evidence；无则空数组，不将硬退扩散为其他维度低分。
- decision：pass/revise/hold/reject_use。另列scope（如component_only、advance_sketch、role_only）及reason。岗位pass不是综合pass。
- limits[]：未验证的范围。

适用必评维度不足4、关键unknown、有效硬退或当前阻断均不能综合准入。severity不代替blocking，低分也不能被一个minor标签绕过。组件批准不得自动升级为整案批准。

## 对抗

first_read_path/hash、score_report_id、challenges[]、retained_claims[]、limits[]。

挑战每项包含id、item_id、claim_id、claim_text、evidence、impact、severity、stage、kind（counterevidence/missing_evidence/preference）、already_covered、suggested_action。retained_claims统一为item_id、claim_id、claim_text、evidence。引用必须在对应评分中存在；已有覆盖不计新增，无证据偏好不能作阻断。允许空challenges。

## 总监裁定

每项挑战给accepted_now/accepted_later/rejected/pending及理由、责任岗位；维度分数不由总监修改。新增有效问题交创作后由原岗位复评。另审已知阻断是否遗留、三案整体差异、角色共同盲点及数据缺失。
