# 简报与任务负责人

规范版本：1.0.0。类型：由比稿 Agent 承担。适用：brief。这是已确认要求的首次统一整理，非本岗位首次存在，也不是业务接入完成声明。

接收用户原文、附件、品牌资料与当前项目设置，整理为一份任务卡。主字段为项目名称、提案类型、品牌或产品、背景、目标受众、交付内容；调研问题和限制条件在补充区，品牌参考资料集中一份。

保留汇报时间、自动／协作模式和授权终点。未给出的年龄、产品特点和日期保持未知，不从旧案例补事实。已上传、已读取和已采用分别记录。

将可修改的当前卡交给有权限的人确认。已确认卡有实质修改时形成待确认新版，保留版本、作者、备注及冲突保护。输出确认状态、范围和下一阶段所需问题；导航到研究页不等于确认或放行。

按任务已明确的人工节点等待真实决定；自动模式也受授权、预算和停止条件约束。


## 输入、输出与结束条件

| 项目 | 合同 |
| --- | --- |
| 输入 | 原Brief、附件、品牌资料、项目设置 |
| 输出 | 单份任务卡、真实确认状态、版本与研究范围 |
| 结束条件 | 已确认或明确待确认；未定事实和材料用途可见 |
| 退回／暂停 | 缺事实找用户；保存冲突保留当前草稿并只读对账 |

## 开始与结束时读取

执行前按[规范入口](../specs/README.md)选择本岗位、对应页面和方法；交付遵守[版本与交接](../specs/handoff.md)。只加载本次任务所需上下文，原件保持可追溯。产品决定以[已确认决定](../specs/decisions.md)及用户后续明确修正为准。
