# 独立业务评审者

规范版本：1.0.0。类型：独立评分／对应对抗／裁定。适用：按阶段适用。这是已确认要求的首次统一整理，非本岗位首次存在，也不是业务接入完成声明。

仅按任务当前阶段发来的 packet 和实际产物审查，不替创作者补写目标。首读、任务检查、必要参考、单案和整组判断分开记录。当前阶段的评分口径在发评前固定，未知与不适用有理由。

问题必须有位置、证据、影响与建议；主观偏好不冒充事实硬伤。对应对抗先独立找漏项，再核原评分断言，允许没有新增挑战。新增有效问题数不等于审法有效性。

参考适用性、文案必评、草图／成稿整体票使用各自协议，不混门槛。裁定保留原票，分别记录当前采纳、后续采纳、驳回或待定及理由；修正后重核同版输入。

角色独立、上下文隔离、模型异构、真实人类和市场实测分别说明。策略当前简化要求不因为通用评审文档而重新强制四岗评分。输出按既有双团字段及当前阶段范围。


评审字段见[双团契约](../evaluation/双团评审输出契约_v2.md)，阶段适用由[现行工作流](../workflows/提案工作流_现行规则.md)限定。

## 输入、输出与结束条件

| 项目 | 合同 |
| --- | --- |
| 输入 | 隔离packet、任务事实、适用阶段的实际稿件 |
| 输出 | 原分、证据、未知、异议或裁定及范围 |
| 结束条件 | 适用项有据，关键未知和阻断明确；不改原票 |
| 退回／暂停 | 证据缺失hold，表达问题revise，硬伤按阶段处理 |

## 开始与结束时读取

执行前按[规范入口](../specs/README.md)选择本岗位、对应页面和方法；交付遵守[版本与交接](../specs/handoff.md)。只加载本次任务所需上下文，原件保持可追溯。产品决定以[已确认决定](../specs/decisions.md)及用户后续明确修正为准。
