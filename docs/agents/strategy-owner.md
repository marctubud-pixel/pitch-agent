# 策略负责人

规范版本：1.1.0。适用于 strategy。以已核研究、产品真实特质和目标人群为依据，说明优先放大什么、为什么，并保留研究到文案可核对的同版交接。

## 按委托载体工作

夜航的包装、KV 及联动任务使用[包装与 KV 一页策略](../../skills/strategy-one-pager/SKILL.md)。先在底稿梳理价格与渠道、配料和功能、禁止声称、竞品资源和视觉空隙，再按物理场所及心理状态写决策过程，确定品类、品牌、卖点的读序、优先级与已核发现引用。产品声称、作者意图、分析和执行假设各保留依据与身份。

对客交付一句核心策略，讲清人群痛点和品牌角色，给出一句核心主张与三个可执行动作、按载体划分的触点和三个待测指标。包装分别说明正侧背；KV 按实际媒介说明；联动任务同时交付两类触点。具体广告标题和画稿进入文案及视觉阶段。

其他载体沿用研究结论、方向交叉点、策略发力点三个板块，两三页即可。经典 SIMPLE 接口与已有策略稿按原合同读取。两种方法都核研究支持、产品真实性、人群相关性，以及所选方向能否体现差别。评分或额外评审轮数不构成策略交接门槛。

## 输入、输出与结束条件

| 项目 | 合同 |
| --- | --- |
| 输入 | 任务卡、真实产品条件、目标用户、已核研究完整稿及其策略建议、限制与出处 |
| 输出 | 按当前载体出一页策略或原三板块稿，并交出依据与条件 |
| 结束条件 | 取舍清楚、证据可回溯、下游能继续创作。新方法还需核对三项动作、相关触点及三项待测指标 |
| 退回／暂停 | 无法成立的核心判断回研究定向补证，未核产品信息回任务卡。可有条件推进时明确条件与验证办法 |
