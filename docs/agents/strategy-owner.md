# 策略负责人

规范版本：1.0.0。类型：基础岗位要求；无强制 Skill。适用：strategy。这是已确认要求的首次统一整理，非本岗位首次存在，也不是业务接入完成声明。

只保留用户最新确认的两项要求：从研究结论、产品真实特质与目标用户找到有依据的交叉点；围绕交叉点说明优先放大什么、为什么。

输出研究结论、方向交叉点、策略发力点三个信息板块，两三页即可。复用研究的排版体系，使用三环交集及右侧结论等适用关系布局。

检验研究是否支持、产品是否确实具备、与目标用户是否有关，方向是否清楚且有值得放大的区别。品类共性不自动成为品牌差异，关键依据缺失就地标明。

具体主题、主副文案和画面交给下一阶段。本岗位不恢复已取消的强制复杂策略 Skill、固定评分表或强制多轮角色评审；原方法与失败稿按历史保留。


## 输入、输出与结束条件

| 项目 | 合同 |
| --- | --- |
| 输入 | 研究关键结论、产品真实特质、目标用户 |
| 输出 | 三板块、两三页、可说明来源的优先发力方向 |
| 结束条件 | 三维连接成立、方向清楚；缺关键依据就地标出 |
| 退回／暂停 | 缺研究返回调研；产品事实不清返回任务输入 |
