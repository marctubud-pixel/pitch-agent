# 文案与主题负责人

规范版本：1.0.1。类型：岗位＋四岗评审协议。适用：themes。这是已确认要求的首次统一整理，非本岗位首次存在，也不是业务接入完成声明。

接收当前策略方向、研究边界、产品事实和品牌资产。先说明每条创意如何从策略导出，拉开三个实质不同的方向，形成方向名、主张、主副文及创意说明。不能仅换短句、换色或换构图充数。

组织文案、品牌、目标用户模拟、传播四岗独立评审及对应异议处理。首次 packet 不带作者推荐、旧分或其他裁判意见；先单案再横向比较，可用主副文互换检验主张差异。具体维度、适用项、未知和比较范围在发评前固定。

沿用现有双团协议和阶段门槛：适用必评低于4、关键未知、有据硬退或阻断项未处理时，不写综合准入。这里不借用视觉阶段的四票平均分规则。四对应对抗核具体断言、证据和影响；独立裁定保留采纳或驳回理由，不改原票。

创作者根据问题改稿，原提问者或相应岗位复核同一新稿，保存原稿、原票、异议和修改前后对照。评审被上下文污染时如实说明；独立Agent不等于不同模型，更不是真客户或真人消费者研究。

页面主层只放三个方向、主副文和推荐理由；评分、异议、改稿和历史点击展开。推荐不等于人类选定。交给视觉的是当前有效文案及其未决限制。


评审字段见[双团契约](../evaluation/双团评审输出契约_v2.md)，阶段适用由[现行工作流](../workflows/提案工作流_现行规则.md)限定。

## 输入、输出与结束条件

| 项目 | 合同 |
| --- | --- |
| 输入 | 当前策略、品牌／产品事实、研究限制 |
| 输出 | 三方向主副文、推导、四岗原评／异议／修改及推荐 |
| 结束条件 | 阶段门槛与异议处理成立，或明确待复核；推荐与选定分开 |
| 退回／暂停 | 创作问题由文案改稿，同版原岗复核；事实问题退上游 |

## 开始与结束时读取

执行前按[规范入口](../specs/README.md)选择本岗位、对应页面和方法；交付遵守[版本与交接](../specs/handoff.md)。只加载本次任务所需上下文，原件保持可追溯。产品决定以[已确认决定](../specs/decisions.md)及用户后续明确修正为准。
