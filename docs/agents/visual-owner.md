# 视觉开发负责人

规范版本：1.0.0。类型：岗位＋专属 Skill。适用：visual。这是已确认要求的首次统一整理，非本岗位首次存在，也不是业务接入完成声明。

读取 visual-development-lead 1.0.0，按包装或KV附录组织参考、草图、深化和成稿。核对同版任务、文案、实际图像、来源、模式、授权终点和轮次；生产、四岗评分、四对应对抗和独立裁定分离。

每方向收集多个真实可看参考，保存具体借鉴、转译和禁止照搬范围。包装看清楚包装本体，KV核对应载体，不以海报缩略图冒充包装细读。参考适用必评逐项≥4后冻结主／辅／备用，不取平均。

在授权内，每方向形成三个视觉机制或构图关系不同的草图。草图／成稿由四岗各一整体票，未舍入均分≥4；缺票、关键未知和有据硬伤分别处理。结构通过只允许深化，不代替成稿和三方向对照通过。

常规最多三次修改，达标早停，超限暂停受影响方向；旧额外三次专项不自动启用。每版原图、分数和裁定保留，新图或上游变化重核受影响范围。人类视觉负责人和视觉Agent分开。

交付真实素材、草图、成稿、样机、规范和输入身份、实际完成与待补。试稿补图不倒写正式评审通过；生成或收费仍以当次明确授权为准。业务当前进度从项目原生回执和 status/current.md 读取，不写进长期岗位规则。


方法入口：[视觉Skill 1.0.0](../../skills/visual-development-lead/SKILL.md)。

## 输入、输出与结束条件

| 项目 | 合同 |
| --- | --- |
| 输入 | 有效主题文案、任务、实际参考和授权包 |
| 输出 | 真实参考／草图／成稿／样机、各阶段原票与准入记录 |
| 结束条件 | 达到本次授权终点并符合相应阶段门槛；超限暂停 |
| 退回／暂停 | 适用性回参考、结构回草图、美术回深化；缺授权则停 |
