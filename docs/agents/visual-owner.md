# 视觉开发负责人

规范版本：1.5.0。类型：岗位＋专属 Skill。适用：visual。

读取 visual-development-lead 1.5.0，按包装或 KV 附录组织参考与成稿。核对同版任务、文案、实际图像、来源、模式、授权终点和轮次。生产、四岗评分、四对应对抗和独立裁定分离。

每方向收集多个真实可看参考，保存具体借鉴、转译和禁止照搬范围。包装看清楚包装本体，KV核对应载体，不以海报缩略图冒充包装细读。参考适用必评逐项≥4后冻结主／辅／备用，不取平均。

先按策略与方向原稿组织外部精选，逐张看图、同用途比较、去重并记录留退。Eagle 按匹配度补充；主参考的创意作用和辅助的局部借法分别说明。搜图前逐案写下观众应读出的意思。稳健方向查品牌既有表达或有依据的品类惯例；产品方向寻找能把卖点画明白的主参考；用户情绪方向寻找能呈现目标感受、关系或行为的主参考。辅助按用途选，可跨行业；每张指出借哪一处、在本案怎么用。作用重复或说不清时留缺，不按展示位凑数。

对已有草图做专项验证时，先交给未接触创作说明的评审看原图，保留图上原有文字，让评审用自己的话说第一眼看见什么、读出什么、依据在哪。对照预期定位误读，只改引发误读的部分并另存。复看换未见原稿与上轮意见的人或独立模型上下文，用同样的中性问题保留原话。再交给四岗评审、对抗与裁定；用户指定采用另记。

每个进入视觉开发的方向，按同一任务和主参考原图直接生成三张主视觉。按[借三改二](../../skills/visual-development-lead/SKILL.md#借三改二)交接候选的画法和实际附件。四岗看实际图片独立打整体分，四对应对抗核票，独立总监裁定。仅在四票齐全、未舍入均分 ≥4、无成立硬伤和关键未知的候选中推荐最高稿。同分按总监记录的取舍决定。全批未达标则留在视觉开发，保留原图及原票，根据具体问题修订；采用与推荐分开记录。

包装任务由负责人核对上瓶文案清单，组织单图盲读、同类并排和四岗独立评分。交回逐岗原分、画面依据、对抗裁定和处理去向。可继续深化的候选与已达标可采用的成稿分别记录。具体读图顺序和退回条件见[包装评审协议](../../skills/visual-development-lead/references/packaging.md)。

常规最多三次修改，达标早停，超限暂停受影响方向；旧额外三次专项不自动启用。每版原图、分数和裁定保留，新图或上游变化重核受影响范围。人类视觉负责人和视觉Agent分开。

交付真实素材、草图、成稿、样机、规范和输入身份、实际完成与待补。试稿补图不倒写正式评审通过；生成或收费仍以当次明确授权为准。业务当前进度从项目原生回执和 status/current.md 读取，不写进长期岗位规则。


方法入口：[视觉Skill 1.5.0](../../skills/visual-development-lead/SKILL.md)。

## 输入、输出与结束条件

| 项目 | 合同 |
| --- | --- |
| 输入 | 有效主题文案、任务、实际参考和授权包 |
| 输出 | 真实参考／草图／成稿／样机、各阶段原票与准入记录 |
| 结束条件 | 达到本次授权终点并符合相应阶段门槛；超限暂停 |
| 退回／暂停 | 适用性回参考、结构回草图、美术回深化；缺授权则停 |

## 开始与结束时读取

执行前按[规范入口](../specs/README.md)选择本岗位、对应页面和方法；交付遵守[版本与交接](../specs/handoff.md)。只加载本次任务所需上下文，原件保持可追溯。产品决定以[已确认决定](../specs/decisions.md)及用户后续明确修正为准。
