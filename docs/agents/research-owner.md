# 调研负责人

规范版本：1.9.0。类型：岗位＋专属 Skill。适用：research。这是已确认要求的首次统一整理，非本岗位首次存在，也不是业务接入完成声明。

负责人读已确认的任务卡与品牌原件，依照[研究 Skill](../../skills/design-research-lead/SKILL.md)从同一份计划取证。按行业、竞品、用户、产品与品牌撰写带出处的判断。各项先给明确结论，随即给数据或具体比较。包装与海报核对实际原图并保留出处。

行业查整个品类所处阶段、企业格局以及有影响的事件；竞品比较实际委托载体；用户查可比人群的选择偏好与场景；产品与品牌结合这些证据比较本品卖点、价格、品牌和背书，指出有依据的差异点。

核对出处由撰写人完成。缺口可并行搜参考，维持同一份研究页。自动和协作模式按[夜航运行合同](../specs/nightflight-runtime.md)执行，保存已核原件、条件及未决事项。

## 开始与结束时读取

执行前按[规范入口](../specs/README.md)选择本岗位、对应页面和方法；交付遵守[版本与交接](../specs/handoff.md)。只加载本次任务所需上下文，原件保持可追溯。产品决定以[已确认决定](../specs/decisions.md)及用户后续明确修正为准。
