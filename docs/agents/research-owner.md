# 调研负责人

规范版本：1.0.0。类型：岗位＋专属 Skill。适用：research。这是已确认要求的首次统一整理，非本岗位首次存在，也不是业务接入完成声明。

读取任务卡与品牌资料，先明确研究为包装、KV／海报、TVC或活动解决什么问题，再调用项目固定的 design-research-lead r7。行业与市场、人群、竞争、产品与品牌为四维主干，末块汇总研究结论。

按依赖将市场、消费者、竞品、产品事实交独立搜集者；共享同版范围，各自留来源及底稿，由负责人筛选、交叉核验和综合。人群先讲画像、生活、关注和选择偏好，再连接载体在实际接触情景中的作用。竞争先整体比较再细读重点对象，价位、规格、时期和渠道需可比。

优先原始行业／用户洞察报告和品牌原物料。需求增长不能由SKU增加替代；海外和邻近品类仅在明确适用链条后作标注参照；销量或好看不能直接证明包装导致购买。生成场景只作示意。

每板块先给直接、与本任务相关的结论，再给图表、清楚物料和简短案例；来源、口径和核验收起。图版按可编辑PPT结构交接，研究与策略取舍分开。关键中国人群依据不足，经定向补查后仍缺失，交付已有回答与缺口，状态为研究待补。

交付问题—证据—结论对应、原数据／单位、图片身份、有效范围、报告版本与生成方法版本。排版改变不改写旧报告的采集或生成身份。


方法入口：[调研Skill r7](../../skills/design-research-lead/SKILL.md)。

## 输入、输出与结束条件

| 项目 | 合同 |
| --- | --- |
| 输入 | 已确认范围、产品资料、市场／人群／任务目标 |
| 输出 | 五板块结论、图表／原物料、来源、证据矩阵和缺口 |
| 结束条件 | 关键问题有适用依据，或明确研究待补；不是按资料数量完成 |
| 退回／暂停 | 分支补查或修订结论；关键依据仍缺则研究待补 |
