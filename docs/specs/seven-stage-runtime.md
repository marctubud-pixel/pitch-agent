# 七阶段运行合同

规范版本：1.1.0。业务方法沿用[现行工作流](../workflows/提案工作流_现行规则.md)，本合同约束新旧记录、可执行范围和状态判断。当前落地为七阶段协议、受限研究、同版独立读者及研究交接；采集与后续生产仍按实际缺口停止。

## 协议与历史

新建受限服务项目持久化`workflow.version: proposal-seven-v1`，业务顺序为brief、research、strategy、themes、visual、layout、delivery。references、sketch、visual是视觉内部执行步骤；不建立新的content_review岗位或页面。

无workflow的旧快照保留原解释、ID、原票和依赖，不能自动重写成新协议，也不因页面隐藏节点而签准入。旧全局STAGES继续服务历史记录；新协议从独立守卫进入，版本未知或阶段序列不符即拒绝。

当前新项目原生授权终点固定research，人工节点仅允许strategy、copy、visual、final_review的既有存储身份。只支持研究生产；旧复杂策略、参考、草图、内容审阅、排版和终审生产入口均不能借新协议直接推进。模式更新另需有效合同，当前拒绝旧set-policy。

## 版本与交接

原生revision与任务卡ID用于乐观锁和输入身份，业务Brief版本按确认边界折叠。来源登记绑定当前任务卡，改版不自动沿用旧卡来源。研究原稿绑定inputVersionIds，Brief更换或未确认会令当前研究过期，旧文件与原评保持历史。

交接先核生产者原件及同版范围，再核接收者实际报告。状态至少区分未开始、待核验、待交出、待接收、待放行、历史／过期。研究报告存在不等于研究有效；人工声明已保存不等于模型负责人已接收。策略续接和研究放行分别授权，本轮策略始终不可执行。

研究事实核验、充分性、独立读者回环、生产者交出、消费者接收、实际放行分别检查；缺项、重复、错稿或过期均不放行。旧generic acknowledge-handoff/release-stage不能绕过新协议。创作者与独立核验、读者、接收者保持既有职责隔离。

## 固定研究方法与实际执行

新研究任务保存design-research-lead的版本r7-20261109和方法包SHA，实际执行从项目固定文件读取Skill及适用合同、任务方法、复核、读者回环与图版附录，加入研究请求。原生数值研究的调用回执按同一份实际prompt重建验证；方法字节变化时拒绝套用旧任务。方法被加入请求不自动证明模型已充分遵守其语义要求。

默认受限服务不创建执行器，不扫描或恢复旧job。显式配置并启用时，只执行当前研究请求指定的job，不推进策略或其他项目。配置、方法、来源、产物和原生模型回执必须分别保留；合成provider用于合同验收，不登记成真实调研。

## 当前研究读者运行

研究前保存问题登记、完整任务卡和方法身份，并由实际生产任务消费。预定一至两位独立读者读取完整可见报告正文，保留六维复述、逐题回答、综合与策略约束、具体问题、原始回执及限制。当前无像素输入，不把正文阅读称为实际看图。

问题进入既有typed修订引擎。新版绑定真实修订祖先、逐项处理和原文引证，再由新独立调用复查。未解决问题保留原ID及关键性；旧负票、未决调用或缺席不能被新标签遮盖。按[读者运行合同](../development/research-reader.md)计算全部同版席位与原件资格。

完整reader证明进入交接basis和owner原始packet，不能只改页面绿灯。HTTP快照及交接/放行前核真实研究与读者文件；坏原件保持待核。理解通过不提升事实充分性、消费者验证或人类批准。原事实、readiness、semantic、双owner报告、人工节点及授权终点继续独立成立。

## 当前未接范围

默认没有执行器。显式配置只处理本次指定任务，不扫描或恢复旧job。PDF原件可保存；解析、自动采集、其他品牌格式HTTP存储、简洁策略及后续仍待接。真实供应商与费用沿原暂停边界执行。合成HTTP提供方及工程操作员用于验证接线，不签真实研究质量或业务批准。

实际范围与原件见[读者核验](../development/research-reader-verification-20261111.md)。本合同不把原案例升级为新生成身份，也不恢复在线PPT编辑保存专项。
