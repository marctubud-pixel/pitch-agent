# 排版后终审协议

规范版本：1.0.0。本文件将既有终审的岗位分离、实际看图和交付合同收拢到稳定入口。不新增终审分数线，不声明正式运行时已接通。

## 输入与准入

终审负责人接收排版生产者的完整交接包，核对任务、Brief及当前head、原稿与证据、Deck与实际逐页渲染、导出文件及原生回执、页与元素对应、实际原图及SHA、原评与未解决问题、方法版本、授权终点和人工节点。当前正式任务要求的风格、版次和页面须齐全，不能用某一案例的一份Deck替代多版合同。

下游接收者明确记录接受、退修或待核及原因。缺稿、错版、缺必要原生证明或读取不到实际像素时保持待核。已明确授权的单稿本地诊断可以执行，但不因此得到正式业务准入或交付权限。

## 五职责及独立关系

| 职责 | 实际核查对象 |
| --- | --- |
| 内容 | 是否回答任务、事实与推理、前后逻辑、页序、完整性与重复 |
| 视觉 | 实际逐页的图文、字形、层级、溢出、比例、页间节奏及原图落位 |
| 品牌 | 品牌和产品事实、资产与主张、三方向差异、原图与实际落位一致性 |
| 用户理解模拟 | 在明确人群及场景下能读懂什么、哪里误解；不得推成真人偏好或购买效果 |
| 传播 | 主副信息、阅读与记忆、场景适配、推荐范围和有无效果越界 |

每职责有主读和另一独立审读上下文，两路分别形成自己的完整结论，随后各有一个对应的文字质疑角色。独立裁定者读取五职责完整原评和质疑，记录结论与理由。创作者、两路审读者、质疑者和裁定者按职责隔离，原票不可覆写。

首读材料不含作者推荐、旧分或其他审读者意见；任务核验另给足够的任务事实与来源。原稿内已经写出的推荐如无法移除，必须说明非全盲，不以“独立Agent”冒称完全盲审或不同模型。

## 实际看图与覆盖

每职责的两路审读均覆盖本次要求的所有实际页面，保存页身份与看图记录。原页不能用文字提取、缩略拼贴或样本代替。视觉与品牌同时核必要原图及其实际页面落位，其余角色按适用范围读取完整源材料。

页间衔接、同稿不同风格和原图落位比较必须有明确对应，页码相同不表示内容对应。正式多版覆盖、材料打包和预算按既有正式合同执行，不能把手工单稿审读当作该图谱已执行。

仅看文字原评的综合、质疑与裁定者不得声称自己看过像素。像素事实仍有争议时记未知，另存预先声明输入、角色、范围和资源的实际看图补核计划；补核完成再裁定，不能凭摘要强判。

## 问题、退修与决定

每项问题保留原编号、职责、版次与具体页或对象、原句或原图、证据、影响、严重性、责任人、处理状态和需重核范围。裁定分别记录采纳、后续建议、驳回或待核及理由，原命名空间和定位不转换成方便通过的其他位置。

新增事实矛盾、来源错误、强制要求缺失、错版和原生证明问题按证据处理，不能被平均分抵消。主观偏好与可选优化可保留异议。已知演练设定、研究缺口和试稿限制随稿，不反复制造同一新增待办，也不因本轮未发现新硬伤而关闭原有缺口。

内容事实退研究或简报，策略取舍退策略，主副文退文案，原图或视觉表达退视觉，版式及导出退排版。修改形成新身份后，原提出岗位或适用独立角色复核受影响内容及最终产物。比稿Agent检查跨阶段影响，不代独立角色签票。

终审没有通用数字准入线，视觉图像的均分≥4只用于其原阶段。终审审读结论、业务资格、人类决定、导出内容核对和正式交付分别记录。人类可在权限内指定采用并保留异议，不能将未证实事实或缺原生证明改写成已核验。

## 交付接收与结束条件

终审生产者提交完整原评、质疑、裁定、已处理及未决问题和最终对象。交付接收者读取该生产者原报告，独立核对同版对象、限制及人工决定。排版生产与终审接收、终审生产与交付接收构成两次双向交接，不能用四个改名调用冒充实际签收。

实际下载至少区分浏览器触发、真实文件已定位、SHA已绑定及内容已核对。检查页序、原文、图片字节、来源、图表工作簿及可编辑范围；PowerPoint原生渲染、在线编辑和保存恢复未实际执行时明示未验。最终批准只作用于其绑定的输入与文件，上游或文件变化使受影响批准待复核。

正式任务完整满足本次合同且按人工节点取得真实决定后，才记正式交付；仅本地诊断完成可以交出诊断和演练文件。完成通知继续受真实渠道和授权约束，文档不启动外部消息。
