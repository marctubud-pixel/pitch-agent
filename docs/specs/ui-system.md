# 中文桌面UI基线

规范版本：1.1.2。用于工作台页面，不覆盖提案作品自身的品牌配色和原始证据语言。

统一维护者为[工作台UI负责人](../agents/workbench-ui-owner.md)。[页面索引](../pages/README.md)指定业务内容责任与各页保留结构，开发统筹派发实现，独立UI审核者复验；业务负责人不单独改公共视觉规则。

- 使用中文桌面界面；移除外语切换和手机产品模式。用户原文、资料原文及历史图保留原语言，必要中文释义与原文分开。
- 保留现有蓝色与中性色体系。首页用蓝色左文件夹、雾灰白右列表、B方案纸卡层次和错落标签；其他页与之呼应，不能一律纯白或全页同一模板。
- 项目仍有五个区域，生产前台为七阶段；人类在线、AI岗位和后台状态分别表达。
- 主层优先任务、结果、图表和图片。详细来源、方法、完整评分、异议与历史按需展开，入口仍可发现。任务卡只有一份，字段命名和摘要一致。
- 阶段想法和版本记录在右侧；意见绑定实际对象和版本，未真正落实不能标“已更新”。右上角人类成员和权限见[协作页面](../pages/team.md)。
- 文本框等高且对齐，禁拖拽，超出内部滚动；新建通常三行，项目任务卡主区五行。图片保持比例，缺图标明真实状态，不用占位图冒充已完成。
- 页面主操作在首屏或相应任务上下文，状态和原因清楚。保存失败、冲突或未完成操作保留草稿；权限由服务边界验证，不能只隐藏按钮。
- 图表保存数据、单位和原生结构，预览与PPT共用数据。生成情景和样机标示意，研究缺口不由美术效果掩盖。

每轮被修改页面按[UI审核岗位](../agents/ui-review-owner.md)核实际运行、目标桌面及边界。内容质量和UI核验分别记；未测不能写通过。精确字号、色值和组件尺寸沿现有设计变量，只有具体可见问题支持时才改；不在这份文档凭空发明新设计系统。

## 当前实现定位

仓库当前开发源根为 `apps/workbench-preview`，保留原scratch活跃源和旧预览。`src/main.tsx`按顺序加载全局CSS，`src/styles/app.css`定义基础变量，`palette.css`、`refine.css`、`experience.css`、`workspace-refine.css`等后续层可能覆盖前层。具体阶段还有各自样式和组件，当前不是单个CSS文件控制全站。

修改前核实际计算样式与导入顺序。共享变量、导航、任务卡或协作组件变化时，UI负责人列出实际受影响页面和状态再复验，保留浅深主题及目标桌面边界。现有结构能解决的问题就在原组件修正，不能靠追加一层覆盖绕过不明来源。

配置HTTP地址只表示选择适配，不表示连接成功。当前占位实现应显示后端未接通，错误使用面向使用者的中文，不显示源码路径；服务真实请求和能力验收完成后才能显示相应已连接状态。
