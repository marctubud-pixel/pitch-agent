# 文案三方向创作与交付

规范版本：1.10.0。适用夜航项目的文案与主题阶段，也适用于获得授权的定向修订。实验分支的新文案由写作 Agent 起稿并自选，负责人从三句中推荐一案。

## 单负责人实验分支的文案

夜航实际入口使用文字 API 中配置的 DeepSeek，加载[原版 slogan-engine](../../skills/slogan-engine/SKILL.md)全文。创作以本轮 Brief、研究文字和策略为依据，按原件定位受众、找动机和创意连接。写作 Agent 自拟三个实质不同的方向，每案保留三到四条主标题候选及用途，另写同案通用副标。各案的主张、机制和策略承接与候选一起留档。创作方向和字数按本案决定。包装案的 slogan 表达提案主题，候选用途限于提案展示或明确委托的其他传播触点。盒身印字随已确认的产品信息交接。

写作 Agent 从每案原候选各选一句，并保留备选。作者逐字引用主标里承载创意的措辞，写出读者单看主标能记住的动作、画面或意思，再核对 AB、AC、BC 三对的创意差别。价格、时段和预约等信息可放在副标或信息栏。它们构成创意连接时也可进入主标。只剩告知信息或两案雷同时，作者重做相应方向。引用不在原句中或缺少任一对检查时，夜航退回本次作者输出。

比稿负责人收到通过作者检查的三句和上游材料，推荐其中一案并给出一句理由。正常交稿调用写作和推荐各一次。后台保存原候选、作者自选号、自检、推荐及回执。已有文案按原记录读取。协作模式由人另选采用方向。

## 历史双团基线

### 构思与交稿

读取本版简报、研究与策略，再分别尝试三种创作任务，每种使用一次。方向名称按项目自拟，呈现顺序按本案安排。

| 创作任务 | 起点与写法 |
| --- | --- |
| 稳健延续 | 有品牌历史时，找出可以延续的语气、意象或成熟表达，并说明这次如何发展它。没有品牌历史时，可沿用本案研究有依据的品类常用表达，同时交代品类依据。 |
| 品牌或产品特征放大 | 选取有依据的一项品牌特征、配方、原料、工艺或使用特征，把它转成读者能想象的动作、比喻或画面。让标题中的具体措辞承接这个事实。 |
| 用户氛围或情绪放大 | 从研究支持的一个具体时刻或情境起笔，写清谁在做什么、产品何时出现，以及这句话如何契合当时的情绪。 |

每案提交以下字段。创作者在这里交候选稿，总监依据实际原票、异议及必要的复核记录给出推荐。

| 记录 | 内容 |
| --- | --- |
| 标识、职责、名称（`id`、`duty`、`name`） | A、B、C 各有一个方向，每项创作职责也各出现一次。 |
| 依据（`basis`） | 从本案当前上游材料逐字摘取可定位的一段原文，支撑这项创作选择。 |
| 主张、机制、策略承接（`claim`、`mechanism`、`strategyLink`） | 分别说明要让人记住什么、通过什么具体创意表达、与策略如何相连。用主标题互换检验差异，两案交换仍完全说得通时重写机制。 |
| 主标题（`main`） | 每案交付一句。单独读也能理解，单案判断引用这句原文。 |
| 风险（`risk`） | 具体指出谁可能误读哪一句，或创意在哪种条件下难以成立。 |

## 用 slogan-engine 寻找连接与改句

本项目采用用户提供的《slogan-engine · 中文口号创作引擎》中的创作步骤。只读来源是附件 `slogan-engine-完整版.md`，SHA-256 为 `b79000179b4df961d67acb662e66730bf97df88b7f5d2ca6493fd0beb36bc239`。创作与改稿均加载[完整版原件](../../skills/slogan-engine/SKILL.md)。每案先冻结三个实际候选，再由独立会话仅看句子分别复述和判断转述意愿。作者据此逐条记录淘汰理由、保留原句及打磨版本、声律、触点延展和取舍。版本族再次隔离盲读，合格主标题才送双团。业务改稿另存改前改后及理由，改字重新盲读。研究没有近期口号样本时，撞车风险标待核。回写用户偏好须等实际反馈。

1. **先看物料和说话的人。** 定位读者在什么场合、以谁的口吻、用多长的注意力读这一句。回到研究与简报，分辨购买人和使用人、明说的需求与此刻的实际落差。便利本身可以是动机。
2. **找能成立的连接。** 把一个能从上游找回原句的产品或品牌事实，与一个实际动作、物件、关系或具体情绪相连。写一句直白的话，说明为什么这两端此时会相遇。换成无关品类仍然同样通顺时，回到材料另找连接。
3. **先写清，再选手法。** 根据连接选用反差、比喻、视角转换等有意义的表达，用读者日常能说出口的话写主标题，选择一个能让这句话成立的事实或动作。读者要靠作者解释才能复述的句子，先检查连接本身。
4. **根据问题改句。** 需要变短时记录删掉了哪层信息，关键信息需在主标题内保留。需要变准时调整说话人、动词或事实落点。已有准确的口语可以保留。在预计使用场合复读主标题，保留有用途的写法和被否理由。
5. **生产和判断分别留痕。** 候选稿由双团按「四岗与双团如何执行」的匿名首读和任务核验要求独立评判。后台续创依据原票和裁定选择重找连接或局部改句，前台只呈现达到发布条件的版本。出稿不以候选数量、字数或押韵形式代替业务判断。

## 夜航原型的三种写法

以下名称、主文和顺序均来自用户指定的「提案台-夜巡」独立 HTML，同源码包 `src/data/content.ts` 的 `DIRECTIONS` 对照核实。它们用于解释手法，新项目以本案事实和策略另行创作。

| 原位置 | 方向名 | 原主文 | 手法 |
| --- | --- | --- | --- |
| A | 慢半拍 | 今天，慢半拍也没关系。 | 用山雾和留白把“暂停半拍”变成可见的符号，让品牌已有的安静气质延伸到日常片刻。 |
| B | 夜里见 | 下班了，夜里见。 | 认领晚上八点以后的时段，以便利店冰柜、末班地铁和亮灯的窗，建立茶作为夜间无酒精选项的情境。 |
| C | 岩上生花 | 老岩茶，开新花。 | 把白桃和桂花的风味转成“岩石上开出花”的形象，以拼贴和贴纸表现新喝法。 |

这里 B 从使用情境出发，C 从风味出发。A、B、C 是原型中的展示次序。历史青屿继续使用其原方向、原句、推荐和原评审记录。

## 单案准入：三项共通要求和一项方向任务

每条主标题有四项结论。总监逐项写明判断，引用标题原句及相关依据。四项都成立才算该案通过。事实或含义仍有关键疑问时，记录具体疑问和需要核对的材料。

| 每案必查 | 通过时能回答的问题 |
| --- | --- |
| 事实准确，归属清楚 | 谁做了什么？能否从上游找到依据？品牌、产品、原料和产地的关系有无说反或夸大？ |
| 单句读得懂，念得顺 | 只看这一句，读者最自然的理解是什么？指代和节奏清楚吗？若有两种读法，是否会读错核心意思？ |
| 能接上本案策略 | 原句中哪条可辨认的线索接住了本案策略？只要求它承接与本方向有关的部分。 |

第四项按创作时登记的 `duty` 选择，A、B、C 是卡位。每案只承担自己的一项任务。

| 方向任务 | 成立条件 | 青屿的判断示例 |
| --- | --- | --- |
| 稳健延续 | 能从标题读出沿用的品牌识别线索。有据可循的品类惯例也可作为起点，需说清它如何用于本案。 | 瓶上的青山与茶里的泉水能否让人想到青屿？ |
| 放大品牌或产品特征 | 能说清品牌或产品做了哪项具体选择，以及这项选择属于谁。 | “挑水”指青屿为无糖茶选配方用水。若容易被读成顾客买水回家泡茶，指出造成误读的词。 |
| 放大用户氛围或情绪 | 能理解什么人被产品的哪个具体线索触动，以及产生了怎样的感受。 | 看见茶里的虎跑泉水，是否自然引出对杭州的亲切感？泛泛的同行跟选撑不起这个方向。 |

## 组内差异与推荐

单独比较 A/B、A/C、B/C。每对引用两条标题，记录它们的创意或读者最终得到的信息有何实质差异。若两案只是同义改写，保留各自的单案裁定，在组内差异处指出重叠点及修改对象。三案及三对差异都成立，才发布整组。

推荐结合本次提案的优先目标，写清更容易留下的**记忆点**、转述时能保留的**核心意思**、更适合的**使用场景**，并说明取舍。品牌更突出、读起来更短、或更适合货架扫读，均可成为两案都能用时的选择理由。若扫读时会把事实读反，则引用原句，回到共通要求里的准确性或可理解性判断。模拟读者的观察只说明文字潜力，真实记忆、购买和传播效果须另有证据。

## 四岗与双团如何执行

1. 文案、品牌、目标用户模拟、传播四岗分别匿名首读，只收编号和标题。记录第一理解后，才看必要的任务、方向职责和上游事实，独立指出原句支持什么结论、哪里有疑问。岗位只登记实际观察到的项目，允许多岗观察同一处，也允许某岗没有补充。
2. 四个对应对抗岗各自先找遗漏，然后核本岗原票。有异议时给出引文和后果。总监合并针对同一处文字、同一实质问题的观察，保留各岗出处。同一句歧义形成一条可执行的修改意见。
3. 总监对四项准入分别裁定。保留原票与分歧；原判有误时由原岗在冻结稿上复核，稿件有误时改相应标题并另存新稿。某岗更喜欢另一句或认为一案难记，可写进推荐理由。任何退稿意见均须能定位到准入项或组内差异。
4. 单案、组内差异、推荐理由分别记录。程序以四项裁定和三对差异验证发布条件。岗位观察保留原值，不取平均。人类采用单独记录。

历史版本沿用原稿和当时的原票。此前的十六项分数可回查；新规则从新评审开始生效。

## 定向续创与成案发布

双团指出可修的创作问题时，在后台把问题、对应证据和可改范围交回创作者。只改受影响的方向及字段，其余内容逐字保留。每次另存候选稿，保留原票、裁定、改动及后续复核的版次关系。原判错误用同稿复核处理。遇到证据不足、达到执行上限或调用失败，保留最后一个检查点与未解决事项。

A、B、C 三案分别达到单案要求，A/B、A/C、B/C 逐对比较后的整组差异也通过，才发布新的整版文案。未通过的候选只在后台续作，前台继续读取最近一次发布。推荐与人工采用沿用各自记录。

### 历史试验 · 青屿完整 slogan Skill 对照

上一轮采用提炼规则，A 沿用原稿，C 沿用原主文。本轮三案从同一份策略独立起稿。执行用户提供的《slogan-engine-完整版.md》，原件 SHA-256 为 `b79000179b4df961d67acb662e66730bf97df88b7f5d2ca6493fd0beb36bc239`。

每案记录场合、价位、视角与唯一任务，从用户动机找到产品与生活的连接，再选用有成立条件的写法。围绕连接发散候选，用七道闸筛选并留下淘汰理由。记录不同长度、节奏、用途的版本和取舍。独立盲读记录原句、复述与行为回答，竞品查重记录样本来源与覆盖边界。完成触点延展和原方法六项执行表，按原附录检查。成长记录在用户反馈后回写。

创作自检结束后按双团流程评冻结稿。改动主副文须关联新的稿件与复验记录。单案、三对差异、整组与推荐分别记录，整组通过后才向前台交付。对照稿继续绑定上一轮票据和推荐。对比时应注明两轮重写范围不同。
