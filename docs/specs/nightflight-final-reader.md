# 夜航排版后三岗本地终审与直修规范（Case B 执行版）

> 规范版本：1.2.5（沿用用户提供的 v1.2.0 三岗与权限规则）
>
> **执行模式**：**Case B（三岗审读 → 合批直修 PPTX → 渲染复验 → 人类验收发布）**
>
> **适用对象**：已完成版式生成的客户提案 PPTX（海报 / 包装 / 视频 / 混合提案均适用）

终审美术岗在实际渲染页独立核对图注。逐件定位区分实物、线描与印刷规格，接收采用图身份与实页待逐条核对的图注。确认违反客户要求的事实计 P0，一般装饰数可由版式直接改成可核的场景描述，计 P1。

## 1. 准入核查与分批读图（Gate 0）

1. 工作台将同一批 PPTX 的**原生页面文本、演讲者备注、每页图片对象数量**及**逐页渲染预览图**交给终审。
2. 审读**严格按顺序每次最多读取 4 页**，记录可定位到页码的客观观察。
3. 若出现**页面缺失、错版、图片张冠李戴或渲染页次不匹配**，立即终止终审并退回版式重排。
4. 逐页对照上游 **Brief、已定策略、已选主副标、数据出处及采用原图**，核对 PPTX 正文有无改动原意、图文是否对应、实际字号与裁切是否影响阅读。

## 2. 三岗独立审读职责

审读拆分为三个独立视角（可分 3 个子 Agent 并行执行，或按顺序完成三轮角色视角扫描），统一输出结构化改稿项：

### 2.1 逻辑审阅（Logic & Perspective）
- **叙事衔接**：检查前后页逻辑是否顺畅（背景 → 洞察 → 竞品 → 策略 → 方案呈现 → 对比 → 下一步），有无跳步或重复。
- **提案者视角**：确认全文站在“面向客户的提案顾问”视角表达，剔除自说自话或内部流程视角。
- **数据与口径严谨性**：严查同一图表内**混排不同统计分母/不同调研口径**的问题；核对百分比、同比、排名、来源标注是否与上游研究依据一致。在同类参考页，按具名竞品及该页附带的同版出处核查规格；本品规格要求按原委托的载体和页面职责核查。与对应来源冲突、写成本品事实或未满足已确认的当页要求时，按 P0 处理。趋势页按同一条原文核对发布年份、研究品类和适用范围。实际页已限定、并与来源相符时，误读风险可保留为措辞建议。

### 2.2 措辞优化（Copy Clarity）
- **听众可读性**：把长句、堆砌词和书面绕口表达压缩为“大屏 3 秒能读懂”的短句。
- **去内部研究腔**：识别并改写上游调研笔记残留词（如“茶叶线索”“系列页并列列出”“核心需求边界”等），转译为自然、克制的对外提案语言。
- **红线约束**：**严禁擅改已定策略结论、严禁改动已选主副标原句、严禁编造未经核实的事实或删去待核实/合规边界说明**。

### 2.3 美术审阅（Visual Craft）
- **消除纯色孤立排版**：严查“纯色背景页仅居中放一张单图/色块图”导致的左右大面积空洞与粗糙感；改用**展陈双线画框 + 左右极简展签/看点锚点**，或融合**无文字暗调场景氛围图/用户图**补足画面层次。
- **材质与默认投影清理**：检查所有卡片、色块、线框、细分割线是否继承了 PowerPoint 默认灰阴影导致画面发闷；生成/修稿层必须显式清除阴影节点（`shadow.inherit = False`、写入空 `<a:effectLst/>` 并将 `effectRef` 的 `idx` 设为 `"0"`）。
- **品牌资产与配色利用**：检查已有品牌色、品牌 Logo、字号对比是否得到充分且一致的利用；避免同一组并列编号/徽章出现无意义的跳色。
- **跨页视觉节律**：统一全册章节眉标、页脚品牌标识、页码位置与对比度（深色/亮图背景上的页码必须清晰可读），确保核心产品图不裁切、文字不压线、不溢出。

## 3. 改稿项记录格式与权限熔断（直修边界）

所有问题按统一字段记录：
`编号 | 页码 | 审稿岗 | 级别（P0 必改 / P1 建议） | 问题 | 证据 | 改法 | 责任阶段`


P0 指本轮交付里的事实或数据错误、违反已确认要求、影响客户选案、遮挡或缺失关键信息。P1 指改善表达或美术的建议，有权限时同批修。已写清且只影响后续制作的资料，放入待确认。源材料已注明待核时，可把成稿纠正为待核。已选策略、主副标和采用原图按本版交接。方案或作品备注的重绘、替换提示只说明后续制作。品牌待定且同版采用原图的独立品牌核对已证实占位时，记录后续事项。命名冲突逐字对照已定用词、本页原生文字和采用原图读字。真实错字、缺少已确认的品牌资产或未核清的冲突继续按必改处理。

| 责任阶段 | Case B 处理权限 | 说明 |
| :--- | :--- | :--- |
| **版式 / 视觉 / 图表拆分 / 轻措辞润色** | **允许直接修改（默认执行）** | 包括拆分混排口径图表、重排孤立单图页、清除默认阴影、补充无文字场景氛围图、统一眉标/徽章/页脚、去除内部调研腔。**严禁覆盖原版 PPTX**，必须另存新版本。 |
| **上游策略 / 已选主副标 / 缺失商品事实 / 采用原图重绘** | **禁止越权直改（强制拦截）** | 不得代客户拍板或改写核心策略与主副标；仅在改稿回执中标明需退回的责任阶段与原因，交由人类确认后再执行。 |

## 4. 2–3 轮执行闭环

1. **第 1 轮｜全册三岗审读 + 合批直修**
   - 按 ≤4 页/批读完全册，合并逻辑、措辞、美术三岗改稿单。
   - 将权限范围内的所有 `P0` 与 `P1` 项**一次性合批改入新版 PPTX**（保留原版文件以便回退），重新渲染全部逐页预览图与整套全览拼图。
2. **第 2 轮｜视觉复检 + 细节精修（必做）**
   - 重新查看全览拼图及所有被修改的单页渲染图，重点排查修稿后是否引入次生问题（文字折行溢出、分割线压字、暗/亮背景上页码对比度不足、默认阴影未清干净）。
   - 发现任何视觉或对齐瑕疵，立即执行二轮微调并重新渲染复验。
   - 同一岗位在新版实图和正文上重新核对其意见。最终必改清单以复验时仍需处理的项目为准。
3. **第 3 轮｜终验封版（按需，最多 3 轮封顶）**
   - 仅当第 2 轮复检仍有未闭环的 `P0` 问题时触发；确认零 `P0` 缺陷后封版交付。

## 5. 最终交付与人类签收

终审完成后，向提案人交付以下 3 项结果（由提案人审阅后决定直接发布或微调）：

1. **精修新版 PPTX**（与原版区分命名，保留原版可回退）。
2. **整套全览预览图（Contact Sheet）**（便于 1 分钟内扫视全局版式与节奏）。
3. **精简 Before / After 改稿回执**：列出已落地的全部 `P0/P1` 修改项（页码 + 改前问题 + 改后结果），以及如有被权限拦截、需人类拍板的上游问题。

> 正式双路五岗终审及人类签收仍按 [排版后终审协议](final-review.md) 执行。
