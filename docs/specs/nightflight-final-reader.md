# 夜航排版后本地审读

规范版本：1.1.0。

工作台把同一批 PPTX 的原生页面文本、图片对象数量和每页 Deck Studio 预览交给终审。按顺序每次读最多四页，记录可定位到页码的观察。出现页面缺失、错版或渲染页次不匹配时退回版式。

v3 逐页稿附各页引用的研究依据和原图观察。审读逐页对照原 Brief、已定策略、已选主副标和本页原图，检查 PPTX 正文有没有改动原意、图文是否对应、实际字号和裁切是否影响阅读。已定策略按材料核对，纯表达偏好可作建议。图上的事实、设计意图和待补素材各按原材料表述。

改稿项记录页码、问题、证据、改法和责任。逐页稿扩写或抄错回版式修本页文字，图文位置回版式调整，确需改变上游内容时退回其责任阶段。重新排版生成新一批 PPTX 和页图，复验本版实际结果。完整意见可在终审查看。正式双路五岗终审及人类签收仍按[排版后终审协议](final-review.md)执行。
