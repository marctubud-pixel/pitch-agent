# 提案排版 · 试行

排版负责人维护本方法。按[试行交接规范](../../docs/plans/客户提案结构与排版交接_试行.md)接收逐页提纲，负责把每条判断清楚地呈现在页面上。业务门槛、原稿身份和交付检查沿用[排版负责人合同](../../docs/agents/layout-owner.md)。

## 先登记前提

核对逐页提纲的适用场合、页码、标题、核心判断及其对应的证据或作品版本。确认放映画幅与阅读尺寸。分别登记品牌 Logo 原件及使用限制、VI 主辅色、项目 KV 色、工作台 UI 色，注明出处和适用对象。缺官方资产时记为待补，可沿用已确认的提案样式做演练。作品保留自己的颜色。未经授权不描摹 Logo 或推定品牌色。

确认上游版本。对每组材料区分产品事实、研究证据、创意主张、模型观察和人类采用；新旧稿并存时，建立方向、图片、原票的对应。不同轮次、不同候选集合的分数不能直接用来比较方向。

## 根据提纲逐页配模板

使用编稿人填好的客户标题及作品／判断。页库的问题、材料清单和填空提示留在后台；必要材料待补的页保留演练标识，不能当成已齐的客户稿。保留逐页表的实例标识和页码，另列“表达任务 → 页型 → 选择理由 → 放什么”。先查工作台已适配模板，再查 Deck Studio 原包。夜航可借阅读层级和翻页方式。只有模板具备真实导出能力，才能用于可编辑交付；缺页型时记录缺口，采用能传达同一关系的已适配页型，或交工程适配。

事实比较用同屏图或同口径图表，单件作品给足可见面积，动作与层级的判断保留相应细节。项目色只作用于已登记的范围。内容超容量，先回查这一页是否承担了两个问题，再决定拆页、改页型或移到附录；不为塞进模板删证据口径、改产品主张或把图表拍平。

封面在放映尺寸上应能直接读出品牌和本次议题；逐页检查模板实际显示了哪些字段。三案总览可用小图识别方向。需要读者判断同类差异时，使用可以看见差异的并排大图，比较主体的可见尺寸，单看图片外框等宽不能证明可比。复用带标签的对照板时核对图内顺序，并保留板图来源。

## 用实际产物回验

从同一 Deck 预览、导出。逐页对照结构表，记录页号、看见的偏差、问题来自页序／模板／源材料／导出中的哪一处，以及改过后用什么检查复验。至少实际走一次翻页、跳页和下载；核 PPTX 页序、文字、原生图表及工作簿、图片比例与来源身份。预览可见与 PowerPoint 原生渲染分开记录。读者能否理解结论、是否愿意采用，留给实际读者判断。一个样本里暴露的问题先写成试行修订，跨品类规则需有相应样本支持。
