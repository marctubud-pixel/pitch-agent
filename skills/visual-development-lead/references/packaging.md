# 包装任务

先核品牌或产品导向、SKU、容器/包材、实际展示面、尺寸与用途；缺少尺寸时概念可研究，不能声称可生产。保留原包装图字节与来源，明确可借的配色、材质、构图或容器关系及不可搬来的品牌身份。

草图核正面主角、品名与品牌信息层级、实际文案长度、必要色块和产品/主题关系；需要看侧背面或结构时单列缺口。包装成图并排检查直接沿用同版已核品类、商品形态、出处及文件指纹的包装原图。按证据范围作并排比较，不再用本案的具体规格重筛同类图。创意主参考可以来自其他适当载体，包装对照独立按真实商品正面核验。成稿核各面关系、微字可读性、印刷/材质限制与实际渲染。生产参数和法规须由相应证据或专业核验支持，图片精美不证明量产或合规。

样机仅在明确授权后制作，标明模拟材质、比例和未验证内容。包装参考不能自动充当用户偏好、当前趋势或完整方向通过。

概念提案的选定方向交付设计主题与简短说明、看清包装正面和立体形态的整体效果图、字体/图形/材质及工艺意向的关键细节。涉及瓶身与外盒时展示组合关系；其他视角按实际需要提供。刀模、精确尺寸与印刷生产文件属于后续深化，不把概念表现称为可直接生产。

## 包装主视觉怎样评

**交接文字。** 提案方向名和 slogan 留在提案页，用来指导信息层级、图形或场景。包装本体只排已确认的品牌、品名、规格和产品信息。制图提示词单列包装允许的字样，依据客户简报和实际产品资料核对。青屿的「一口到虎跑」用于提案命名，正面依次读到「青屿」「无糖茶」和泡茶用水。

外盒写整盒装量，单件写单件规格。只要求外盒正面时，成图可只展示盒身、露出部分内装或表现单件取用。客户委托完整内装演示时，逐件按位置核对实际物件。同款取用场景核空位及盒外对应的物件。盒面印字、图案、被遮住的件数都不能作为已看到的实物。

目标价或拟售价保留在提案材料。给生图提示词作者的资料中只交接未确认、价签不上画的状态，按原始 Brief 核对金额与展示授权。客户明确要求价格入画时，在指定载体保留金额、单位和价格限定。

**先盲读，再并排。** 将候选逐张匿名交给独立读者，保留图上印字，隐藏简报、推荐、旧票及其他方案。中性提问“第一眼看到了什么？图上发生了什么？你认得品牌和品类吗？哪些信息要靠读字？还能怎样理解？”原话按图封存，注明读者与上下文。随后揭示任务，同时交付候选原图、可追溯的真实同类包装原图，以及按近似瓶身高度制作的缩小并排图。保留名称对应、图像身份、缩放条件和比较范围。修订时照原条件加入未改的对照稿，分别盲读后再并排。模型观察仅作本次概念评审。

| 岗位 | 给分前必须回答的问题 |
| --- | --- |
| 用户 | 卖点动作能否独立读懂？举出主角、动作和落点，区分插画传达的关系、文字确认的事实及其他合理读法。以泡茶用水为例，3 分可对应“水和茶都有，关系靠猜”，4 分对应“看见泉水入茶”，5 分还须在约定的小尺寸读清动作与水源说明。 |
| 传播 | 在真实同类中哪处最先被注意？缩小后还能否把这个特征归到品牌？分别记录“认出蓝岩那瓶”和“读出青屿”等不同结果。 |
| 品牌 | 逐稿核对包装本体可见的印字原话和位置，区分盒身、画面标题与价签。若主题句、方向名或其他不符用途的字样印上盒身，或发现错字、无法核对印字，该稿退出推荐。核对必要产品字样的位置与字号。 |
| 视觉 | 与每款参考逐对指出相同与不同的位置，检查轮廓、颈标、正标形状、文字层级、主图关系、笔法和配色。再核小尺寸构图。区分品类共性和某款参考有辨识度的组合；结论限于实际看过的参照。 |

**原票与裁定。** 四岗各按职责独立交一张 1–5 分原票，说明得分依据和仍欠缺之处。1 表示与任务冲突，2 表示需较大修改，3 表示部分成立，4 表示成立但有局部缺口，5 表示本项在约定条件下完整成立。同分逐项交代共同边界及各稿长短。四对应对抗先独立找漏，再核对应原票，不另打分；总监逐项裁定并保留分歧。沿用四票齐全、未舍入均分 ≥4 且无成立硬伤和关键未知的采用门槛。可以指定未过线的稿件继续深化，并明确记录其状态。

并排评审可使用阅览副本，保存与原图对应的指纹。品牌岗提出印字疑点时，另逐张看原图，只带产品 Brief，逐字记录包装本体、具体位置和读图回执。对抗与裁定据原图记录区分盒身印字和画面标题，保留第一张原票及已核实的硬伤或缺口。

**按证据退回。**

- 动作被误读、正面主次错误或缩小后必要文字读不清，退给视觉执行。指出要改的具体部位、应保留的有效关系和复看条件。
- 若同一参考的多项特有选择在相同位置成套重现且证据成立，阻断采用，退回重新找参考和组织构图。单一常见瓶型或颜色只作观察。评审记录具体相似性，避免把有限对照写成法律认定。
- 地点意象泛化时回到实景资料。记录照片出处、可见特征、缩小时能保留的轮廓及实际转译位置。青屿借滴翠崖突出岩板与斜向开口重画泉口；岩石入杯是设计表达。[杭州日报《虎跑泉与虎跑寺》](https://hzdaily.hangzhou.com.cn/hzrb/2026/02/27/article_detail_1_20260227A122.html)
- 实际取水和生产用水等事实回品牌方核资料。地点照片可作造型依据；产品声明另记证明材料及待核范围。区分概念深化与正式使用。

**青屿例解。** 蓝岩新版与第 2 稿对照时，新版用户、传播、品牌、视觉原分依次为 4、4、4、3。两位新版盲读者认出品牌和泉水入杯，缩小后水源说明仍难读。均分 3.75，可继续深化，未达采用门槛。这组原分记录一次具体判断，其他项目须按实际图稿重新取票。
