# KV 与海报任务

先核传播目的、品牌/产品导向、节点、主 KV/子海报身份、画幅、媒介、必要文案与指定比较范围。同用途主 KV 才进入直接比较；活动现场、促销物料、视频截图等分别标为背景、视觉借鉴或待核，身份待核不凑同类数量。

参考可跨行业，但须回答当前视觉问题。方向卡写可检验的“参考方法 → 目标载体 → 主题/品牌关系”、比较对象和至少一种具体创新假设；参考阶段审假设，草图核兑现。只换标题即可通用于其他节点且缺有效画面关联时退回，节点关联可以由场景、器物、纹理、天气或行为支持，文字可辅助。

**桌面海报的借改。** 把策略的受众和传播目的交给视觉。客户明确指定的画幅、渠道和位置随任务卡交接。各案按创意决定画面焦点和构图。用实际主参考原图核读五项，记录可见位置和比例。每稿三项借法引用该读图记录，两项改法交回可画的新目标。简报、方向、实际附图和最终提示词随稿保存。

**slogan 上图。** 按当前方向读取已选原句，作为清楚可读的主标题排进成图。提示词包含完整原句，排版可换行。独立读图只接收当张原图，逐字抄录实见标题和位置，标出缺失或无法读清。核对定稿的字词、数字和标点。抄录与定稿不符或无法核实时，该稿退出自动推荐。

**成图验收。** 每案将主参考与三稿放在一起，逐稿核对三项沿用和两项变化，对原图和成图分别写可见依据。桌面单独委托海报或 KV 时，开画前标出有明确出处、可用实图核对的必需条件。实图有证据违反这类条件时挡稿。常规借改偏差或看不清的细节作为评审意见。全自动模式再逐对比较三个方向的实际代表稿，说明标题和留白的位置、主画面的分布、景别和视觉焦点。有证据确认主要结构雷同时，拦截实际对比的代表稿，备用稿留待并排核对。看不清的部分记为待核意见。换画风、配色、字体或局部动作不能抵消构图雷同。保留原图、批次评分和退回原因，供改稿及人工采用。

草图核主角、元素取舍、位置比例、留白、信息顺序与实际文字长度；创意须帮助核心主张，不以新奇抵消误解或表达损失。成稿核色彩、字体、光影、材质与统一感，按实际风格判断。单图合格后核三个方向是否机制不同，不能只换左右位置或道具。未经实测不声称热度、偏好或传播效果。

## 主参考交接与画面核验

把各案已准入的美术任务、主图应用方式和禁用素材一起交给制图。投放地点写在媒介要求中，只有本案需要的场景、道具或动作才进入画面。配色管主色和色彩对比，布局管标题、留白和画面各层的相对位置，景别管主体占比和环境范围，笔法管边缘、线条和质感，字体管字形和字重。原图标志、品牌、联名角色、物件和装饰由本案重新画。

有明确纸幅时按原图实际长宽选择。相反版幅先为该方向补查同向的独立作品。补查后仍采用不同版幅时，说清可转译的相对位置和留白。没有采用的品牌实物图时，按真实品类画容器，用纯色占位。客户明确要印在本体上的字照原样，其余已确认信息排在海报文字区。

逐张用实际候选原图独立核对客户已确认的品牌和产品信息，记录错用品牌、照搬的原图标识、角色或无依据的商品字样，并指出实图位置。已确认的品牌原字及未定标志的干净占位可采用。原图匿名首读中已明确定位的第三方品牌进入合规记录。首读指出下部小字或图标说明时取原图局部核对。纯合规说明保存在模型回执，硬伤只列带有真实位置和内容的违规。实图硬伤独立于四岗评分。Brief 明确 A 系列纸幅及横竖时核对原件像素比例，保留完整图文。

三张稿的五项借改可以用完整轻量阅览图核对，固定候选 1、2、3 先独立记录原图和成图的实见依据，保留两份图件的指纹。再由文字核验对照生图时锁定的条件和已保存的观察。新增边框、图标和背景内容仅在条件明确要求时计入布局。该改变的项须与原参考有可见差别，且符合制图目标。标出的硬条件有疑点时，以原图两两复看一次，保留首读和复读。挡稿证据引用实际图上的具体矛盾。四岗文字意见提供推荐理由，分数留档。文字与品牌核对看原图。整图首读看不清标题或与定稿不符时，用无损裁片独立复读并保留原始首读。需要重画的稿已有复制第三方标识或专有素材的实图证据时，生图用同一主参考的实际五项观察。客户品牌素材按原用途保留。重画后继续与原主参考独立核对。

全自动看到该案没有达标稿时，保留通过准入的原参考、借改组合和选稿证据。优先选已核实硬伤较少的稿，数量相同时按采用次序选。把该稿的硬伤和位置写进生图提示词，沿用原来核定的画面关系和画法。明确采用平涂插画时，主体、商品、手和背景使用统一画法；沿用布局时按目标纸幅重新安排留白。只重做一稿，再对照原图复验。修前原图与替换稿分别保存，修前原图用于追溯和对照。已有仅需修标题标点的候选时优先沿用一次局部修字。仍无可推荐稿时留在视觉。
