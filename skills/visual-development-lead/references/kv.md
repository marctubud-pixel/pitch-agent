# KV 与海报任务

先核传播目的、品牌/产品导向、节点、主 KV/子海报身份、画幅、媒介、必要文案与指定比较范围。同用途主 KV 才进入直接比较；活动现场、促销物料、视频截图等分别标为背景、视觉借鉴或待核，身份待核不凑同类数量。

参考可跨行业，但须回答当前视觉问题。方向卡写可检验的“参考方法 → 目标载体 → 主题/品牌关系”、比较对象和至少一种具体创新假设；参考阶段审假设，草图核兑现。只换标题即可通用于其他节点且缺有效画面关联时退回，节点关联可以由场景、器物、纹理、天气或行为支持，文字可辅助。

**桌面海报的借改。** 把策略的受众和传播目的交给视觉。客户明确指定的画幅、渠道和位置随任务卡交接。各案按创意决定画面焦点和构图。用实际主参考原图核读五项，记录可见位置和比例。每稿三项借法引用该读图记录，两项改法交回可画的新目标。简报、方向、实际附图和最终提示词随稿保存。

**slogan 上图。** 按当前方向读取已选原句，作为清楚可读的主标题排进成图。提示词包含完整原句，排版可换行。独立读图只接收当张原图，逐字抄录实见标题和位置，标出缺失或无法读清。核对定稿的字词、数字和标点。抄录与定稿不符或无法核实时，该稿退出自动推荐。

**成图验收。** 每案将主参考与三稿放在一起，逐稿核对三项沿用和两项变化，对原图和成图分别写可见依据。缺失、不符或无法核实的项使该稿退出自动推荐。全自动模式再逐对比较三个方向的实际代表稿，说明标题和留白的位置、主画面的分布、景别和视觉焦点。主要结构雷同或看不清时，相关稿件退出自动推荐。换画风、配色、字体或局部动作不能抵消构图雷同。保留原图、批次评分和退回原因，供改稿及人工采用。

草图核主角、元素取舍、位置比例、留白、信息顺序与实际文字长度；创意须帮助核心主张，不以新奇抵消误解或表达损失。成稿核色彩、字体、光影、材质与统一感，按实际风格判断。单图合格后核三个方向是否机制不同，不能只换左右位置或道具。未经实测不声称热度、偏好或传播效果。

## 主参考交接与画面核验

把各案已准入的美术任务、主图应用方式和不借内容一起交给制图。投放地点写在媒介要求中，只有本案需要的场景、道具或动作才进入画面。借景别只交主体占比和环境范围。原图标志、品牌、联名角色、物件和装饰由本案重新画。

品牌岗看实际候选原图，对照客户已确认的品牌和产品信息，记录任何错用的品牌、照搬的原图标识、角色或无依据的产品声称，并指出实图位置。有据硬伤不能因均分达到四分而入选。Brief 明确 A 系列纸幅及横竖时核对原件像素比例，图文不能为适配比例被裁去。

全自动看到该案没有达标稿时，保留通过准入的原参考和选稿证据。根据实际缺陷只重做一稿，再对照原图复验。已有仅需修标题标点的候选时优先沿用一次局部修字。仍有硬伤或关键未知时留在视觉。
