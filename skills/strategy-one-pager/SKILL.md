# 包装与 KV 一页策略

以已核研究、产品真实条件和目标用户为输入，回答“优先放大什么，为什么，落实到哪个触点”。对客交付一页。详细推导随原稿交给下游。成稿使用本案语言，案例里的产品事实、价格、配色和指标不能直接移用到其他项目。

## 一、先确定边界和机会

1. 阅读任务卡、研究完整发现及证据、研究给策略的建议和适用限制。列出消费价格带和本品目标价、实际销售或投放渠道、配料或功能事实、禁用或待核声称。区分品牌提供、市场实测、建议值和假设。缺少证明的功效不写入卖点。
2. 解释头部竞品在解决什么问题、依靠哪些资源，以及本案具有什么条件。引用真实案例；作者意图须有原文，研究者推断注明身份。找出在目标场景能验证的竞争空隙，说明什么现象支持它、什么资料会推翻它。单个案例不能证明行业空白。
3. 逐项链接本版已核发现。存在两个解释时说明优先哪个、暂缓哪个及代价。缺口妨碍决定主方向时写清须回研究补什么；可条件推进的假设连同验证办法进入交接。

## 二、确定决策顺序

写出人、物理场所、当时在做什么、有什么顾虑，以及从接触、辨认、理解到决定的过程。对这一情境明确品类、品牌、卖点各自出现的顺序和理由。研究没有测量注意顺序时，把读序作为设计意图，保留可反证的检验方式。

包装分别指定正面帮助第一眼辨认什么、侧面补充什么、背面怎样容纳配料与必要说明。KV 对应实际传播节点、媒介和观看条件，明确产品角色、画面及信息层级。联动任务分别写两类触点，说明哪个信息跨媒介保持一致、哪个随接触时机变化。有价格、尺寸、商标或合规限制时同步带入优先级。

## 三、把证据写成一句核心策略

用「把[品类]从[旧认知]，变成[具体场景的新意义]」起稿。先分开检验句子的两端，再读整句。

- **旧认知**从可定位的竞品表达、商品用途或使用研究中取材。若只看到咖啡馆菜单上常用某种原料，可表述该场景里的既有用途。品牌选择挑战一种看法时，在推导中注明这是品牌选择的叙述角度；只有实际调查支持时，才写消费者普遍这么想或这么感受。
- **新意义**先核对产品能提供什么、渠道使它在哪里可得，以及用户在那个时刻要解决什么事。把这些条件换成当事人会说的一句日常话，落在一种具体感受上。营养健康、替代正餐等利益要有相应证据支持。对于竞品，记录原件可见的做法；对动机和产品真伪的评价须有独立事实依据。
- **校稿**在后台对照初稿、只列产品事实的说明式写法和策略终稿。问三件事：旧认知的来处是否说得清，产品事实怎样在这个场景产生新意义，拿掉哪个形容词也丝毫不影响理解。删去这些空词，让终稿保留必要的动作、场所和感受。

把这句话交到四节中。洞察解释这个人为什么会需要这种改变；角色说明品牌靠哪项真实利益兑现它；主张给出三个能在图稿上指认的动作；首要触点写清消费者在那里实际能看到什么，从而认出这项承诺。其余触点再补充相应信息。

谷间白的给定定位原句：「把燕麦奶从“植物基概念”，变成“通勤路上看得懂的干净早餐”。」此处“植物基概念”是品牌选择讨论的旧认知；“看得懂”可以落到正面品类名与易读的配料说明，“干净”表达读懂后少一点疑虑的预期感受。项目材料须支持具体配料。不得借“早餐”宣称能完整代餐，或将“干净”延伸为健康功效、竞品成分有问题。

## 四、写成一页

| 栏目 | 交给客户的内容 |
| --- | --- |
| 核心策略 | 一句话把产品原先的意义，转成它在特定场景中对某个人的新意义。说明选择的方向。 |
| 人群洞察 | 讲一个能解释选择的具体矛盾或痛点，避免罗列统计或塑造无据人物。 |
| 品牌角色 | 写出品牌在这个情境里担当什么角色、凭哪项真实利益兑现。 |
| 核心主张与动作 | 用一句内部工作主张聚焦一个可支持的卖点。紧接三项可执行的视觉或排版动作，每项说明改哪个元素、放在哪、解决哪个阅读问题。 |
| 视觉与包装触点 | 根据交付形态列正面、侧面、背面，或逐个列实际 KV 媒介；联动同时覆盖。让设计师能按触点开展创作。 |

对客正文先放核心策略大字句，再按两行两列放四小节。第一行是人群洞察、品牌角色，第二行是核心主张与动作、视觉与包装触点。排版按[策略页面规范](../../docs/pages/strategy.md)。

在后台原稿写三项待测指标，各写清测什么、在哪个场景、如何取数。基线、比较对象、阈值注明出处或待测身份。后台同时保留约束、竞品处境与空隙、用户决策链、取舍优先级和已核发现引用，以便复核。正文的主张和动作作为后续创作输入；正式主题主标题由文案阶段产生，具体画稿由视觉阶段完成。

## 验收与交接

检查事实能否回到本版任务卡或研究原件，主张是否与产品相符，三项动作是否互补，触点是否覆盖委托范围，三项指标能否实际观察。把“希望用户三秒认出产品”“某种配色更易识别”“可以支撑溢价”等写成待测假设；拿取率、停留时长、复购均须说明观察方法与可获取的数据。策略提交时保留限制和证据身份，文案与视觉可沿同一依据复查。
