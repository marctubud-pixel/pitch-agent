# 核对视觉事实后再改布局

用于图组语义、遮挡、缺失与测量判断。只核对影响拟修改的事实，不为每个像素生成报告。

## 分开观察、解释和动作

每项关键发现保留四部分，格式沿用用户要求：

- **观察与位置。** 记录实际看到的文字、形状或区域。使用路由和组件，或PDF物理页码及页面区域，能回到原材料核查。
- **解释。** 区分可见事实与尚待确认的用途、身份、流程、因果及阅读顺序。
- **动作的前提。** 说明什么已证实的用户任务需要这项修改。前提未证实时，提出条件建议或保留现状。
- **验证。** 指定回到哪里、怎样检查，不把未来的读者测试写成已观察到的效果。

例如，“两图上下对齐”是观察，“同一人物的两个镜头”是解释。只有实际画面、图注或可靠来源支持人物对应时，才添加人物标签。清楚的行列不能替代内容证据。

## 核对图组身份与顺序

拟改变标签、组别、编号、连线或排列前，逐张查看相关图片，先用中性位置标识定位，例如“第2张图”“标题下方的说明”，再准确描述其可见内容。逐一核对原图与图注，保持原顺序，记录无法确认的身份与关系。

几何邻近、截图外观和模板对齐只能支持空间关系。它们不能独立证明同一人物、同一项目、业务阶段、时间先后或真实交互。身份或顺序无法确认时，可以改善可读性与中性定位，但暂缓角色标签、流程箭头和会改变含义的重排。

## 核对“缺少”“遮挡”和“裁切”

提出补标题、补内容、拆图或去遮挡之前，重新打开相关区域的足够清晰视图；必要时再看完整页面和相邻页，核对已存在的标签、正文及内容边界。

区分“当前没看清”“当前渲染没显示”和“原材料确实不存在”。未提供或无法读取的区域不支持缺失结论。看到图层重叠后，指出被遮的具体必要文字或对象；装饰背景、设备外壳及本来用于演示的遮罩不自动构成缺陷。必要内容完整、阅读任务也未受损时，保留叠图。

## 为数字保留测量依据

当像素、距离、字号或对比度数值决定修改必要性时，实际测量并记录来源、坐标系、尺寸或缩放、工具和结果。Web使用实际DOM与计算样式；PDF可用页面对象、坐标提取或渲染图；位图测量说明图像尺寸及像素坐标。

渲染图像素不等于源文件字号、CSS像素或现场物理尺寸。跨页比较使用相同渲染与缩放，逐页测量，避免将观察器窗口偏移当作页面偏移。

不需要数字时，用能核查的相对描述。估计值明确标为估计，不能单独支撑“必须大幅重排”等硬结论。工具不可用时省略未经测量的精确数值，保留可见事实与验证计划。

## 复看相反证据

实施前回看一次可能推翻修改的证据：标题是否已存在、必要内容是否其实完整、图注是否已解释关系、素材是否只用于氛围展示。若推翻原判断，撤回对应修改并保留更正记录。不要把“需确认”附在一个已经断言为事实的错误解释之后。
