# 任务与证据合同

用于分支委派、结果合并与定向补查。编号在本次研究内保持稳定，便于追溯，不依赖特定工作台接口。

## 研究范围

记录任务卡及版本、设计任务、研究目的、目标市场、人群条件及其来源、购买/使用角色、场景、渠道、研究时间窗口、已知产品事实、假设和限制。用户已确认条件、用户未定条件和研究推测分别保存。

## 分支任务

| 内容 | 要求 |
| --- | --- |
| 编号与问题 | 一项边界明确、能够独立回答的问题 |
| 任务关系 | 它会影响后续哪项判断，不预设答案 |
| 载体作用 | 谁在何种接触情景中，通过该载体需要研究哪一环反应或障碍 |
| 关键性 | 执行前明确是否为进入策略所需的关键判断 |
| 范围与排除 | 市场、人群、时间、品类、渠道及不适用对象 |
| 方法与资料 | 预期证据类型、来源优先级及可用工具；模型按具体问题选用，记录用途与适用边界，不以填模板作为完成条件 |
| 依赖 | 需等谁提供哪些结果；哪些采集可以先行 |
| 资源与完成条件 | 按任务和已有授权确定读取/补查范围；回答到何种程度可交付 |

分支返回候选结论、发现与依据、反例、未解问题、补查建议和实际执行记录。报告“未找到”时带检索范围、已读来源和失败/排除原因。

## 问题与证据矩阵

每行对应预先定义的问题，包含品牌/提案人需要的判断、适用任务与载体、关键性、所需指标/比较、可比条件、负责人、实际依据、回答及限制。回答状态为“可回答”“有条件回答”“尚不能回答”。另记材料的展示去向，使用“主层”“详情”“排除”，并写明它改变哪项任务理解、是否重复及为何值得占据主阅读位置。综合与独立复核逐行判定，补查或收窄回答仍保留原问题。

人群矩阵先覆盖与任务有关的身份、生活与关注、群体差异，再连接情境与选择、载体作用。优先写出有证据的群体描述及差异，不用姓名、职业贴纸或大张生活数据拼成画像。未找到目标群体直接资料时保留较窄的有效发现，并把广泛背景后置；不能用参照数量掩盖核心缺口。包装分别检查需求变化、竞争格局、选择因素、包装作用/审美、可比竞争与产品条件。海报/主视觉、TVC按各自接触、理解、记忆等问题安排，不机械执行包装价带清单。

## 证据记录

每条保留稳定编号、所属问题、原始发布者和出处、原文/图页定位、发布与实际数据时间、研究对象所在地、样本及方法、场景与渠道、品类或SKU、提取事实、适用范围和用途。数值另记指标、数值、单位、分母及是否为作者计算；计算保留输入与公式。没有公开的方法信息保持未知。

来源机构国籍不替代样本市场。原始发布与转载关联到同一个来源；调查、品牌自述、观察、消费者反馈与研究者推断分开。

证据用途：

- 直接依据：可支持所写结论的实际范围。局部样本也只能直接支持该局部样本的描述。
- 有限参照：存在年龄、地区、场景等差异，保留差异及可用范围；不得暗中变为目标群体事实。
- 视觉启发：说明可借鉴的表达，不证明市场表现或消费者偏好。
- 排除：来源、身份或相关性无法成立，记录原因而不进入论证。

数字呈现合同包括指标对象、原始定义、值和单位、增长方向、同比/环比/其他比较基准、统计期、市场渠道、样本/分母及原件定位。原件未明确的字段保留未知。图上显示足以理解数字的口径，其余细节放出处；来源未说明销售额或销量时不能自行补齐。多期比较要求口径一致，分组快照不称趋势。

## 结论记录

保存编号、回答的研究问题、一句判断、支持证据及关系、任务意义、反例与限制、证据状态和核验状态。区分有据判断、有条件推论与尚不能回答；不以伪精确置信度替代说明。

已核验事实不代表由它推导的结论也核验通过。新综合判断沿用原证据范围，不能由多个有限参照累加成已验证结论。

## 最终交付

1. 简述任务、范围、实际执行方式与研究状态，点明关键缺口。
2. 各问题的直接结论及匹配图表/原图模块，一章可有多组图，重要限制随判断显示。按[研究图版规范](visual-boards.md)保留可见口径与来源，并关联同一证据记录。
3. 竞争主层保留跨样本叙事与视觉归纳、例外及采样边界；研究结论按任务关联市场、人群、接触条件、竞争与产品能力。
4. 可展开详情、附录或独立底稿，保存详细分析、价格明细、完整任务清单、证据台账、检索/补查及核验记录。正文保留稳定引用入口，不先展开全部台账。

研究待补说明尚缺什么、已做何种补查及独立核验是否实际完成。避免在多个部分反复重述同一状态和边界。

面向网页与可编辑PPT的语义交接保留内容模块、结论/证据编号、数值及计算、图表系列与类别、独立文字与定性关系、图片资产身份和布局映射。按[图版规范](visual-boards.md)分别验证文字、原生图表、形状及图片的编辑边界。使用排版工具时再保存[模板与整案交接记录](layout-templates.md)，并分别记录研究原生成版本和排版实现版本。机器字段、界面状态和业务写入另按运行环境实现。文件中的概念状态不是工作台已保存的原生回执。

## 参照、策略与证据关系

参照记录保留对象、来源、市场/人群/价位/场景、与纳入用途相符的匹配因素、差异、转用关系、反解释、入选用途及待验证部分。不靠凑齐匹配项数量决定证据资格。四维发现与最终研究结论以证据和前提相连，不凭第一条数据自动拼接。

竞品另记公开策略是谁说的、可见执行是什么、推断是什么、效果证据是什么。价格记录规格、渠道、日期和性质；时代情绪记录人群与实际数据期。

独立读者另有首读复述、具体质疑、负责人答复、修改/补证、实际修订报告复查记录。事实核验与理解状态分别保存，解释不能改变源资料或证据资格。
