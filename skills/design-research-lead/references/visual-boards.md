# 把研究回答组织成图版

在综合每个问题时先选择图形，再写详细分析。图版是研究回答的可视呈现，不增加证据资格，也不替策略阶段决定定位或创意。

## 先匹配问题与证据

逐项记录研究问题、候选结论、证据编号、证据范围、可比条件与图形选择。没有适用证据时，图版说明能回答的范围和待补问题。

| 问题与已有证据 | 适合的主图 | 保留的边界 |
| --- | --- | --- |
| 同口径数量、规模或变化 | 柱状图、点图；连续同口径多期数据可用折线图 | 保留指标、单位、时期、市场渠道与比较基准；销售额变化不改写为需求人数变化 |
| 不同规格、渠道或日期的价格记录 | 按可比条件分组的样本点图、区间图或图片卡片 | 标明规格、价格性质、渠道和采价日；旧价与新价混合时保留分组快照，不连成趋势线 |
| 包装或竞品表达的共性与差异 | 真实物料对照图、带具体观察维度的样本地图 | 清楚区分本品、直接竞品与邻近参照，标明采样范围与未覆盖部分 |
| 接触情景、障碍与载体作用 | 情景图配观察点、接触路径或定性关系图 | 区分实测、原始案例观察与机制参照；定性布局不暗示测量距离或排名 |
| 人群构成、偏好或行为 | 有实际测量时按原样本画分布；仅有定性材料时用引语、条件与差异对照 | 人口比例、偏好排名、雷达评分和坐标须有对应测量；访谈片段不推成人群占比 |
| 产品能力与研究缺口 | 有依据的能力与需求对应图、条件或缺口标记 | 明确事实、推论和未验证连接；空缺保留未知，不填零 |

比例图需有实际分母与可比较构成。同源转载、混合年份报价、主观印象不能生成百分比、雷达评分或趋势。定性图直接标注“定性归纳”或“研究假设”，使用无量化刻度的分组与关系。

## 按问题组织图版

以阅读问题组织图版，把相关信息组合在同一视野。一个图版可有结论、重点数值、图表、情景和短图注；多图服务同一回答时并置，而不让每组数据各占一张大卡。数量与尺寸由必要信息和可读性决定。单个数值通常作为指标，连续可比多期用序列图，横向比较用同尺度图或矩阵。图形不同必须源于问题不同，不能为丰富样式编造比例或评分。

先编排主次，再增加模块。正文读者应能迅速抓住一个主要判断及其关键图证，详细分析由展开入口承接。已有上一版时同视口并排检查图文组合、同屏比较和必要信息；收起详情仍要看得懂。图表数量、留白或文件页数不作为质量分。

人群图先用匹配证据解释群体身份、相关生活与选择差异，再连接载体作用。可用清楚标注的情景图帮助理解购买环境，并置最相关的行为/选择证据；照片、姓名或宽泛代际数据不能替代画像。竞品主层先有整体地图，再有清晰原图与统一观察维度的并排对照，给出共性、差异、例外和范围。放大细看是补充，不用逐件巨图替代横向比较。不同价期或性质的记录可分组展示，真实但不可比的记录保留身份，不拼成现价排名。详细编码放详情。静态样本共性用定性对照表达，不画成时间趋势。

主图内或紧邻主图的可见区域保留指标与单位、数据期、市场或样本范围、渠道及短来源。非数值图标明观察对象、物料或研究时期和范围，未知字段如实注明。来源短名与稳定编号连接原件定位。足以改变读法的限制随图可见，不能只放在展开层。

详细推理、完整价格表、方法出处、检索日志与核验回执放入可展开详情或附录。报告身份、研究状态和重复边界集中说明；会改变图意的单位、时期、范围、物料身份与限制仍随图显示。收起详情后，读者仍能理解结论、图意、证据范围及关键缺口。静态交付用明确的附录入口保留这些内容。

## 页面与后续PPT复用

研究数据、内容模块与布局分别保存。同一模块的页面和导出使用同一组语义记录，包括结论编号、证据编号、原值与计算、单位、时期、范围、图形含义、关键限制及图像身份。按媒介映射布局，不另造一套数值或把定性判断转成评分。这是交付约定，不代表工作台业务接口或编排已实现。

承诺逐项可编辑时按对象交付并验证：

| 内容 | 保留与导出要求 |
| --- | --- |
| 研究数据 | 原值、类别、系列、单位、时期、范围与计算独立保存，关联证据编号 |
| 数值图表 | PPT中保留原生图表及其可改数据；网页从同一数据生成，缺原生支持时如实声明编辑边界 |
| 标题、分析与注释 | 独立文本对象，可改文字、样式和位置 |
| 定性关系与标记 | 独立形状、连线及文本，可分别调整关系、颜色和布局；不编造数值 |
| 产品原图与示意图 | 独立图片资产，可替换与裁切，保留身份和来源；图片内部像素/瓶贴不声明逐字可改 |

整张PNG或SVG只能整体替换时，不能作为上述文字、图表和形状已逐项可编辑的证明。SVG含文字或矢量外观也不自动等于PPT原生对象。PNG/SVG可按任务另供预览或插图，不能替代语义与原生对象交接。

研究图版与整案使用共同的[模板选用约定](layout-templates.md)。采用工作台已适配的版式工坊时，网页和PPT读取同一份引擎排版结果，文字、图表与独立图片随模板槽交接。画布与模板容量按目标媒介决定，不以固定页数替代可读性。整案阶段调整章节、节奏及统一视觉样式，保留研究图版的内容与证据，不重新编造图表或把同屏比较拆成长表。

导出文件本身保留单位、时期、范围、短来源、关键限制和图像身份，不依赖悬浮提示或网页上下文。检查实际导出和目标尺寸下的标题、数据标签、脚注、字体替代及裁切；可编辑交付另实际修改文字、图表数据、形状和图片，确认对象边界。字体采用目标环境可用的字体，可编辑文字不因保留矢量外观而改成整图。图片内嵌交付，裁切不截断包装识别、关键观察点或来源标注。完整出处仍可由稳定编号追溯。

## 保留图像身份

真实包装、海报、影片帧和活动物料优先使用可追溯原件。包装主材优先清楚可辨的单品大图、纯底正面图，必要时补背面/侧面与细节；在实际阅读尺寸确认讨论的文字和图形确实可见。海报小瓶、宣传合成和场景图用于对应传播语境或环境辅助，不能替代包装细节证据。原件不足保留缺口，不以AI重绘或补画瓶贴冒充原图。保留其“实拍”“官方渲染”“宣传合成”或“概念稿”身份，官方发布不自动等于真实产品实拍。

人物或接触情景需要解释时，可按本次授权使用生成图。把生成图作为独立的示意资产记录，在页面和每份导出图版中均显示“AI生成情景示意，非实拍、非研究样本”；该标注不放入仅展开可见的详情。生成图不计入来源数、调查样本、人群比例或真实产品原图，不冒充已经执行的产品方案。原始竞品图与生成示意分别标识，布局不暗示它们具有相同证据地位。

生成示意只帮助理解已有情景条件，不新增市场、人群或效果事实。本Skill不自动发起付费API、生图服务或创作任务；按当前任务已有授权和可用工具执行，没有相应授权时用现有原图或简图表达。
