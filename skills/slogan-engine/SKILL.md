# slogan-engine · 中文口号创作引擎（完整单文件版）

为「一句能被记住、能被论证、能长成战役」的中文 slogan 提供完整生产线。交付物永远是文案本身；策略只存在于引擎里。
本文件自包含，可直接放入任何 Skill 系统（WorkBuddy / Claude Code / Cursor / Codex 等）。附录 A 是可选的机械检查器脚本。

---

## 一、核心原则（违反任意一条即跑偏）

1. **策略在引擎里，不在界面上。** 不追问、不问卷。以一行「明示假设」呈现推导（「我按『她愧疚的不是花钱，是没时间陪猫』来做」），用户一句话可推翻；推翻超过两次才允许追问，且一次只问最关键的一格。
2. **存「连接＋版本族」，不存单句。** 改稿＝连接不变换表达；降维＝换更短表层；延展＝同一连接换媒介。交付是版本族，不是「更好的那一句」。
3. **生成与审核隔离上下文。** 过闸由未读过推导的空白裁判执行（子代理/独立会话只贴句子）。自审无效——上下文会制造合理性幻觉。
4. **执行表必填才算交付完成。** 空格＝未完成。

## 二、工作流（九步，按序执行）

### 01 坐标 —— 先定位，再动笔
产出三坐标，见第三节速查表：
- **场合档位**（分档逻辑：受众拿这句话去干什么）：复述→传播 / 行动→转化 / 感受→共鸣 / 查证→信任 / 引用→仪式
- **价位**：低=处方（越短越好，不许抒情）/ 中=说明书（说具体，给理由）/ 高=誓词（能被消费者转述而不脸红）
- **视角**：卖方立主张 / 买方先说顾虑再给方案 / 第三方给证据

确定**主任务（唯一计分项）＋约束（不计分、一票否决）**。「slogan 也要信任」≠并列计分：传播是主任务，信任降级为约束。需要 ≠ 并列。档位挂「这一次的物料」，不挂项目（招商手册走信任档，招商会主视觉走仪式档）。

### 02 动机 —— 他的落差在哪（最重要的一步）
写 L0 触达者（谁在看/此刻站在哪/给他几秒）→ L1 落差三层（嘴上要什么 / 心里的落差 / 落差归谁管）。
按**四驱动**推：恐惧（怕失去/怕落后）· 向往（想成为/想配得上）· 身份（我是谁/想被看成谁）· 便利（省事省时，无情绪——别给打印纸硬挖情绪）。
**强制双入口**：怕和想要常是同一落差的两面（怕选错＝想要确定性）。恐惧面与向往面各推一遍再决定从哪面切。不强制，产出会系统性偏向焦虑营销，而消费者对焦虑已免疫。警惕反向风险：向往面用多了同样通胀。另有**时间窗口型**入口（怕错过「还敢画错」的年纪，紧迫感来自爱而非比较）。
检查掏钱人与使用人是否分离（亲子/养老/礼品——文案必须让最终念出口的人愿意念）。
预检：动机放进三个不相干品类都成立＝万能动机＝作废重推。

### 03 连接 —— A 连 B
固定格式「A 连 B」（如：精打细算 连 为爱打算；光瓶 连 没有盒子钱）。核心原理：**创作的重点在于连接的新鲜度和准确性**。新连接＝两个从未被放在一起、放在一起立刻成立的东西；旧连接＝公共卖点、行业套话（「形容」不是没有连接，是连接太公共）。
任何后续步骤卡住，回到这里重找连接，不要在打磨硬磨。

### 04 选法 —— 八法，带病历（见第四节）
每次强制指定 2–3 种互斥方法，选方法时把它的「专属病」一起带上。叠音/拆字只做收尾，禁止在表达阶段抢跑。

### 05 表达 —— 先写清楚，不追工整
每条连接 3 个版本（不同方法）。**七条铁律**：
1. **推理步数 ≤ 1**，且按目标受众的知识面数（作者数出来的不算；跳板须是公共知识。「全款拿下的自由」一跳，跳板是房价；「冰球」对不喝威士忌的人是黑话墙）
2. **词的公共性**：主标用词必须是受众日常词；圈内黑话（见第六节词表）只能进副标/详情页。「本体在场」只保证换品类过，「词是公共的」才保证人能读懂——两道都要过。
3. **主标说人话，证据做副标**：主任务是评分权重不是句式指令。主标一步说中落差（「馋是真的，负担是假的」），可验证动作下沉支撑位（「配料表印在正面」）
4. **口语心声不许修病句**：口语类只能选择，不能润色。模型的本能是修改病句，而口语的力量常在那个病句里
5. **具体 ＞ 抽象**：可指物名词（八块钱、去糖去冰、我妈）才有画面；中等抽象词（钱、日子、生活）是默认产出要警惕。具体物有过期风险→交给闸④
6. **句子可以不完整**：半截话不像广告，正是它成立的原因。所有句子都闭合＝都像「文案」
7. **比喻的本体必须在场**：参照物不能代替本体（「这个点还开门的，不止便利店」无「健身/杠铃」＝任何深夜生意都能用＝换品类不过）

### 06 过闸 —— 七道闸，空白裁判执行（见第五节）
**用独立子代理或新上下文做空白裁判，只贴句子。** 毙掉的句子连同毙因一起留档（毙因是信息，不是失败）。

### 07 打磨 —— 三方向，产出版本族
版本族：每条 3–4 版 ×（版本 / 字数 / 适用位置 / 得失），**原版永远保留**。版本之间是尺寸关系不是新旧关系（15 字上品牌片旁白，10 字上电梯屏），不替客户二选一。
三个方向：**变短**（压缩）· **变顺**（对仗/顶针/叠音/换字）· **变准**（挪立场——「我们买过三套系统」→「买过三套系统的人」，自嘲变行业事实，力量来源改变，字数不变。挪立场最值钱）。
**主推必备声律版**：对仗/押韵/叠音/顶针/叠字至少命中一种。对仗本应是生成结构（「少劝他喝，多陪他喝」），不是写完再贴。
压缩记账：每压一次明确丢了什么，能补就挪到副标补回。不知道丢了什么的压缩＝删信息。
三条约束：① 不改意思（改了是重写）② 不丢落点（换品类检验重过）③ 磨完必须复闸（修辞会掩盖问题）。
停止信号（任一收手）：磨完需解释才成立 ／ 落点变了 ／ 连两轮只换字不换结构。

### 08 复闸与交付
所有版本重跑七道闸。**盲审两关分开跑**：
- 可懂关：只贴那一句，问「这句在说什么？用你自己的话讲一遍。」（复述无法伪装；不问「懂了吗」，人会客气）
- 好坏关：另一位裁判，不知道前者结论。问「你会把它转述给别人吗？」「印在电梯里会多看一眼吗？」（行为提问，不评价提问）
- 四格：**懂＋好＝用 · 懂＋不好＝改 · 不懂＋好＝删（最危险，作者最舍不得）· 不懂＋不好＝弃**

**延展测试**（主推句必做）：当场长出三个延展——战役主题＋社媒话题＋线下动作。长不出来＝好句坏 slogan，降级为社媒单张不删。
交付格式（六项，缺一未完成）：① 一行明示假设＋坐标 ② 版本族表 ③ 主推 1＋副推 1 ④ 风险标注（合规/撞车/歧义/时效存疑）⑤ 被毙句与毙因 ⑥ 执行表。模板见第八节。

### 09 回写 —— 引擎从每次使用中长大
**只记分歧，不记一致**（用户选了次优、毙了主推才是一条知识）。**毙因＞选择**（「难理解」是强信号，「只用第一个」是弱信号）。
回写分四级，门槛递增：
- **词级**（热词、失效场景）→ 直接进第六节词表
- **句级**（正/负案例）→ 记「句子＋死因」（如「八岁以后不画错」死因＝三跳）
- **规则级**（铁律/闸修订）→ 须回测全部历史案例后才生效（新规则要能拦事故句、且不误杀「一顶帐篷，全款拿下的自由」「少劝他喝，多陪他喝」）
- **结构级**（工序增删）→ 罕见，完整重跑验证

每次裁决沉淀为**偏好对**（选中句 vs 被毙句＋理由）——这是未来训判别器的语料，用得越多库越厚。偏好**连坐标记录**（档位×价位×视角），防把场合偏好当普遍规则（「这次只要短的」≠「短就是好」）。

## 三、坐标速查表

### 场合五档（受众拿这句话去干什么）

| 档位 | 受众的动作 | 典型物料 | 计分权重 |
|---|---|---|---|
| 传播档 | 复述它 | 上市 slogan、大众广告、户外 | 记忆 40 / 差异 30 / 美感 20 / 得体 10 |
| 转化档 | 照它行动 | 详情页、信息流、私域 | 清晰 40 / 可信 30 / 行动 20 / 美感 10 |
| 共鸣档 | 被它打动 | 品牌片、TVC、节气海报 | 洞察 40 / 情绪 30 / 美感 20 / 记忆 10 |
| 仪式档 | 在致辞里引用它 | 行庆、周年、婚宴、奠基 | 得体 40 / 归属 30 / 庄重 20 / 记忆 10 |
| 信任档 | 拿它去查证 | 招商、B2B、招募、保险 | 可验证 ＞ 可信 ＞ 具体 ＞ 记忆 |

同一句话换档位分数可以完全反过来：「谢谢你，把日子过成家」传播档 90 分，仪式档可能只有 50（太轻，撑不住场面）。

### 价位三档（决定文案重量）

| 档位 | 文案功能 | 写法 | 例 |
|---|---|---|---|
| 低价 | 处方 | 越短越好，不许抒情 | 怕上火喝王老吉（症状+用药+7 字） |
| 中价 | 说明书 | 说具体，给理由 | — |
| 高价 | 誓词／购买辩护词 | 能被转述而不脸红 | 钻石恒久远，一颗永流传（要在婚礼上被念出来） |

错配双向失败：低价配重＝装，高价配轻＝贱。使用周期决定打磨胆量：三年资产要稳，两周物料可以锋利。

### 视角三种
- **卖方**：立主张
- **买方**：先说顾虑再给方案。能力不是共情，是**替用户把他自己说不清的感受说出来**。上口号位必须压到极限（「怕上火」＝整段顾虑压成三个字）
- **第三方**：给证据、给场景

买方视角风险在选哪层顾虑（表面/深一层/说不出口）。选错一层＝替他编造一个他并不担心的顾虑，比平庸更致命。越深越有力，也越危险。

## 四、八法成立条件与专属病（方法是带病历的招式）

成立条件＝把闸前移到方法层；缺一即废。

### 连接策略层（负责「成立」）

| 方法 | 成立条件 | 专属病（死法） |
|---|---|---|
| **新知解释**（用新角度重讲人人知道的事） | 旧事实是**大众已知**（非圈内共识）· 新角度一步可达 · 换品类不成立 · 是真知不是歪理 | 把圈内话当公共事实（「冰球」案） |
| **口语心声**（替当事人说他说不清的） | 说的是当事人自己的处境 · 保留口语松散**不许润色** · 带具体物 | 书面语模仿口语；替人编造他不担心的顾虑 |
| **价值认同**（说出没说出口的价值观） | 人群已认同、嘴上没说 · 没被用烂 · 听众愿意认领 | 品牌自嗨；热词通胀（松弛、匠心） |
| **利益传达**（具体好处或动作） | 可验证可感知 · 数字属实 · 非品类公共利益 · 合规 | 「不上头」式公共语；数字虚标；功效暗示 |
| **二元对比**（两件事对放产生意义差） | 两方**同层面**（动作对动作）· 产生意义差不是文字游戏 · 双方都是真实选项 | 不对称（写给采购看 vs 留给老板疼）；视角串台 |
| **熟语二创**（改写全民级熟语） | 原熟语全民级 · 二创与产品强绑定 · 原熟语未在死亡期 · 不动规范成语 | 「好马配好鞍」：无落点＋拗口 |

### 文字技巧层（负责「收尾」，不独立产出）

| 方法 | 成立条件 | 专属病 |
|---|---|---|
| **叠音**（关键词重复两次以上） | 叠的是关键词 · **下句必须强化或转折** · 只做收尾 | 同义反复（「把日子过成算术题」案） |
| **拆字**（下句拆字重组） | 拆常见字 · 重组产生新义 · 读得顺 | 纯文字游戏；生僻字 |

横向规律：可自动化程度与质量成反比（利益传达/二元对比/熟语二创易执行上限低；**口语心声/新知解释才出精品**且最难自动化）。主力产出通常落在「新知解释＋口语心声」。方法是脚手架，判断是承重墙：去掉修辞还成立的是好句。

## 五、七道闸 · 盲审 · 事故测试集

裁判必须未读过推导过程（独立会话/子代理/人）。

| 闸 | 问法 | 拦什么 |
|---|---|---|
| ① 空白读＋朗读＋数步数 | 只给句子第一反应；读出声；推理几步 | 可懂性（复述检验）＋声韵（开口音收尾响亮、闭口音收敛；拗口活不过口播）＋**步数 ≥2 判不懂** |
| ② 现实核对 | 句里的东西现在还存在吗 | 虚假痛点、时代错位（「导购跟着你」「实体账单」） |
| ③ 视角核对 | 语法主语和立场是同一个人吗 | 视角串台（消费者句子、老板立场） |
| ④ 时效核对 | 第六节四条规则 | 旧词、死词、被行业解决的痛点 |
| ⑤ 换品类检验 | 扔进三个不相干品类还成立吗 | 漂亮但无落点（失恋/离职/搬家都成立＝没落地） |
| ⑥ 撞车核对 | 与同品类竞品近两年口号的语义距离 | 语义撞车＝替别人养口号 |
| ⑦ 档位标尺 | 主任务权重计分，约束只做门槛 | 拿传播档标准杀仪式档合格品 |

**事故测试集（回归用，永不删除）**：① 缺声律版→门禁②应拦 ② 「醒着的夜，需要一支冰球」→词公共性应拦 ③ 「这个点还开门的，不止便利店」→本体缺席应拦 ④ 「八岁以后，他就不画错的东西了」→三跳应拦 ⑤ 「一顶帐篷，全款拿下的自由」「少劝他喝，多陪他喝」→必须不误杀。

## 六、词表与时效规则（09 回写的生长点）

词表由使用过程长出来，**连坐标一起记**（「传播档死了」≠「仪式档死」）。

**时效四条规则**（只查具体的物件/动作/说法，抽象词免检——具体性就是过期风险）：
1. **替代物检验**：替代它的东西普及了吗？（实体账单→APP 推送＝死）
2. **行业共识检验**：这个痛行业集体回应过吗？（导购跟随→无打扰购物＝旧闻。痛点不是因为消失才失效，是因为被解决才失效）
3. **反向词检验**：出现「假X/装X/反X」了吗？（假松弛＝死）
4. **年龄检验**：出圈几年？（0–2 年安全，约 4 年一个生命周期）

搜索技巧：搜「XX＋反感」「XX＋变味」比搜「XX 还存在吗」准得多。
**分级前提**：只有当这句话要被记住时，套话才是病；仪式档的套话是制服不是病（行庆「砥砺」得体，传播档「砥砺」死）。

**热词已死（传播档）**：砥砺·赋能·焕新·抓手·闭环·匠心·重新定义·诗和远方·极致·神器·颠覆·完美蜕变·诠释·助力·打造·高光时刻
**热词将死（慎用）**：松弛/松弛感·情绪价值·内卷·躺平·长期主义·认知升级·少年感·余生（婚宴改用「到老」）·温柔且坚定·与世界和解
**仪式档豁免**：砥砺·奋进·谱写新篇·扬帆起航·共创未来·再启征程（仅限行庆/周年/政务，且不求被记住时）
**圈内黑话（禁上主标，可进副标/详情页）**：汽车 CLTC/NEDC/OTA/CTC/智能座舱/零重力座椅；酒类 单宁/回甘/酒体/余味/冰球/醒酒/风味轮；数码 算力/端侧/多模态/交互范式；通用 方法论/心智/触达/用户画像/私域。判断口径：这个词不是这个圈子的人认识吗？
**失效场景（曾真实现已不真实）**：导购跟着你·实体账单厚薄·BP机·磁带倒带·拨号上网·寄信等回音·老人只会用微信（2026 年老人刷短视频比年轻人狠）。新增格式：`场景 | 死因（哪条规则）| 判定年月`
**品类社会性**（决定时效检查强度）：爱/失去类零折损 · 工业（停机/交期）稳定 · 酒桌/人情类折损最多 · 技术参数换代即死。

## 附录 A · 机械门禁检查器（可选，Python 3 标准库）

用法：`python3 gate_check.py cases.json` —— 机械项全绿 exit 0；任何空格 exit 1。无脚本环境可跳过，改用第八节手动六项勾选（但机械项务必逐项核对）。词表起手与第六节同步，使用中生长。

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""slogan-engine 交付门禁检查器（机械层）。空格=未完成，exit 1。"""
import json, re, sys

SOUND_TYPES = {"对仗", "押韵", "叠音", "顶针", "叠字", "叠排", "回环"}
DEAD_WORDS = ["砥砺", "赋能", "焕新", "抓手", "闭环", "匠心", "重新定义", "诗和远方", "极致",
              "神器", "颠覆", "完美蜕变", "诠释", "助力", "打造", "高光时刻"]
DYING_WORDS = ["松弛", "情绪价值", "内卷", "躺平", "长期主义", "认知升级", "少年感", "余生",
               "与世界和解", "温柔且坚定"]
JARGON = ["CLTC", "NEDC", "OTA", "CTC", "智能座舱", "零重力座椅", "单宁", "回甘", "酒体",
          "余味", "冰球", "醒酒", "风味轮", "算力", "端侧", "多模态", "交互范式", "心智",
          "触达", "用户画像", "私域"]
CJK = re.compile(r"[一-鿿]")

def count_cjk(text):
    return len(CJK.findall(text or ""))

def scan_words(text, pool, label):
    return [f"{label}「{w}」" for w in pool if w in (text or "")]

def check_case(case):
    rows, hits = [], []
    name = case.get("name", "(未命名)")
    main = case.get("main") or {}
    main_text = (main.get("text") or "").strip()
    sound = main.get("sound") or {}
    sound_text = (sound.get("text") or "").strip()
    sound_type = (sound.get("type") or "").strip()
    rows.append(("①主标", "✓" if main_text else "␣", main_text[:24] or "缺失"))
    if sound_text and sound_type in SOUND_TYPES:
        rows.append(("②声律", "✓", f"{sound_type}｜{sound_text[:20]}"))
    elif sound_text:
        rows.append(("②声律", "␣", f"类型「{sound_type}」无效"))
    else:
        rows.append(("②声律", "␣", "声律版缺失"))
    bridge = (main.get("bridge") or "").strip()
    rows.append(("③步数", "✓" if bridge else "␣", f"跳板：{bridge}" if bridge else "未标注跳板词"))
    family = case.get("family") or []
    bad = [f for f in family if not (str(f.get("text", "")).strip() and f.get("chars")
           and str(f.get("use", "")).strip() and str(f.get("tradeoff", "")).strip())]
    rows.append(("④版本族", "✓" if family and not bad else "␣",
                 f"{len(family)} 版" + ("" if not bad else f"，{len(bad)} 版缺列")))
    gates = (case.get("gates") or "").strip()
    rows.append(("⑤闸记", "✓" if gates else "␣", gates[:28] or "未标注闸结论"))
    killed = case.get("killed") or []
    bad_k = [k for k in killed if not str(k.get("reason", "")).strip()]
    rows.append(("⑥毙因", "✓" if not bad_k else "␣",
                 f"{len(killed)} 毙" + ("" if not bad_k else f"，{len(bad_k)} 条无毙因")))
    all_text = main_text + " " + sound_text + " " + " ".join(str(f.get("text", "")) for f in family)
    hits += scan_words(all_text, DEAD_WORDS, "热词已死")
    hits += scan_words(all_text, DYING_WORDS, "热词将死")
    hits += scan_words(all_text, JARGON, "圈内黑话")
    for f in family:
        declared = f.get("chars")
        actual = count_cjk(str(f.get("text", "")))
        if declared and actual and int(declared) != actual:
            hits.append(f"字数不符「{str(f.get('text',''))[:12]}」声明{declared}/实数{actual}")
    return name, rows, hits

def main():
    if len(sys.argv) != 2:
        print(__doc__); sys.exit(2)
    with open(sys.argv[1], encoding="utf-8") as fh:
        data = json.load(fh)
    cases = data.get("cases") or []
    if not cases:
        print("cases.json 里没有 cases。"); sys.exit(2)
    total_empty, all_hits = 0, []
    print("# 执行表（交付门禁 · 机械层）\n")
    for case in cases:
        name, rows, hits = check_case(case)
        print(f"## {name}")
        print("| 项 | 勾 | 说明 |")
        print("|---|---|---|")
        for item, mark, note in rows:
            if mark == "␣":
                total_empty += 1
            print(f"| {item} | {mark} | {note} |")
        if hits:
            print("拦截/警告: " + "；".join(hits))
        all_hits += hits
        print()
    print("---")
    if all_hits:
        print(f"词表/一致性警告 {len(all_hits)} 条（不阻断，但须逐条处置：改写或标注理由）")
    if total_empty:
        print(f"判定: 未完成 —— 执行表存在 {total_empty} 个空格，补齐后重跑。")
        sys.exit(1)
    print("判定: 表已填满 —— 机械项全部通过。人判项（贴皮对仗/新鲜度/得体/能长）仍需独立盲审。")
    sys.exit(0)

if __name__ == "__main__":
    main()
```
