# Client-Pitch Copywriting Polish & Simplification SOP (提案措辞优化与精简操作规范)

Apply this checklist to **every single slide** after drafting the structure and before outputting the final script. You have full permission to trim, simplify, and rewrite awkward upstream phrasing into natural client-facing Chinese—and when client inputs are incomplete, you may add concise, dossier-grounded connective judgments framed as suggestions (`建议 / 待确认`) so the deck reads as a complete pitch.

---

## 1. Five Categories to Cut or Rewrite (五类必改/必删表达对照表)

| 类别 | 禁用/典型坏味道 (Avoid) | 操作指令 | 提案化改写示例 (Use Instead) |
| :--- | :--- | :--- | :--- |
| **① AI / 学术分析黑话** | `直接归因`、`叙事抓手`、`视听同步记忆`、`呈现侧重`、`心智赋能`、`切入空间`、`信息流扫码` | **一律重写为直白人话** | `让人记住产品`、`创意亮点`、`边看边听记住名字`、`看点对比`、`切入点`、`一屏看懂` |
| **② 工程 / 验收单式标题** | `镜头与入画规范`、`触点优先级与取舍`、`产品与任务约束`、`物料交付边界` | **改写成客户视角的自然短语** | `30 秒画面节奏`、`封面三区排版`、`核心需求`、`本轮交付` |
| **③ 文档元信息 / 自我说明** | `共 16 页`、`轻量单载体模式`、`3 方向比稿`、`纯方案本体`、`第六步版式演练` | **直接删除**（客户不在乎文档怎么编的） | 留白不写，直接呈现项目名与方案内容 |
| **④ 内部质检 / 自省免责腔** | `页面未列样本量`、`尚无测试不能保证效果`、`历史视觉记录存在阻断`、`胸牌小字无法辨认` | **正文删除，静默遵守**；需修图的条目移入 `内部备注` | 正文只陈述有依据的事实与来源，绝不堆砌免责声明 |
| **⑤ 跨页抢跑 / 目录剧透** | 同类参考页末尾硬加“本案将聚焦 XXX 实现突破”；目录页把每章细点全部列出 | **删除抢跑后半句与目录小字** | 同类参考页只讲竞品做法；目录页只放 3–5 个大板块名 |

## 2. Four Actionable Simplification Moves (四步可操作精简动作)

Run these four passes on every drafted slide:

1. **砍半句（一页只留本页职责）**：如果一个标题或要点同时包含「别人怎么做」+「我们准备怎么做」两层意思，直接砍掉属于下一页的那半句，让翻页产生自然的推进感。
2. **砍复读（实图已印的字不抄两遍）**：当真实原图上已经清晰印出 0–30s 逐帧台词、音效或流程条时，前面的 `[方向阐述]` 页只写「主副标原文 + 设计思路 + 核心看点」，不把图上的字逐条复抄成文字墙。
3. **砍空词（删掉虚浮修饰语）**：删去没有信息量的形容词与空洞副词（如 `极致`、`全方位`、`深度`、`完美`、`强力`、`有效`），用具体画面、动作或数据本身说话。
4. **控长度（一眼扫完不费劲）**：
   - `标题/重点`：尽量控制在 **18 个汉字以内**，一句话读完不喘气；
   - `解释内容`：每页不超过 **4 条要点**，每条尽量控制在 **35 字以内**；纯图页与金句页果断留白。

---

## 3. Hard Boundaries: What You Must NEVER Touch (不可触碰的保真红线)

- **Verbatim creative copy**: Keep all provided direction main headlines (`main`) and sub-headlines (`secondary`) word for word.
- **Exact numbers & factual scope**: Never distort numbers or expand a narrow statistic into an unsupported claim.
- **No outside fabrication**: Never invent external market stats, competitor quotes, or unverified product claims. Any provisional judgment or recommendation made under incomplete inputs must be derived strictly from existing dossier facts and explicitly labeled as `建议 / 待确认`.

---

## 4. Mandatory Read-Aloud Gate (交付前 3 秒朗读自检)

Before finalizing the script, mentally read every slide's `标题/重点` and section label aloud as if presenting live in a client pitch meeting:

- 念起来是否像真人提案，而不是机器报告或内部验收单？
- 是否存在生硬的书面合成词（如“归因”“抓手”“侧重”“约束”）？
- 这一页有没有抢答下一页的结论？

Any slide that fails any of these three checks must be rewritten before final output.
