# Four Proposal Type Blueprints

Use these blueprints after classifying the pitch into one of the four proposal types (**海报提案 / 包装提案 / 视频提案 / 混合提案**). Treat every blueprint as a **flexible scaffold, never a quota**: only include sections supported by the input dossier, never invent missing logic or unstated recommendations, and follow **One Point Per Slide (一页一重点，不水页、不硬挤)**.

---

## 1. 海报提案 (Poster / KV Pitch)

Typical use cases: Brand campaign KV, single WeChat/social cover KV, series user posters, festival/holiday posters, IP visual sets.

### Variant A: 单载体轻量比稿（如单张公众号封面 KV / 单海报多方向比稿）

1. `P01 [封面]`：项目名称 + 简洁副标题 + 氛围主图（无工程味元信息）
2. `P02 [目录]`：仅列 3–5 个大板块名称（无页码区间、无细碎剧透）
3. `P03 [需求回顾]`：项目任务、目标人群、核心体验与沟通目标
4. `P04 [趋势洞察]`（材料具备时独立成页）：宏观市场与目标客群趋势（简洁注明来源）
5. `P05 [同类参考]`（材料具备时独立成页）：竞品或同类机构传播拆解（支持多图并排对比 + 对本案启发）
6. `P06 [核心策略]`：极简定调页，一句话抛出材料中的核心策略与核心主张
7. `P07 [版式规范]`（材料具备时另起一页）：展开视觉分区、信息层级或三区结构线框示意
8. `P08–P13 [各创意方向呈现]`（按方向循环，每方向 2 页，顺序一致）：
   - `[方向阐述]`：保留主副标原文 + 材料依据的创意逻辑与画面重点（不机械复读图上文字；待修项放 `内部备注`）
   - `[成品展示]`：全幅完整画面展示（`解释内容：无`，标注图号、文件名与横竖画幅）
9. `P14 [横向对比]`：全案并排视觉对比（注明横竖图等宽或等高对齐），客观列出各方向切入视角与取舍
10. `P15 [决策与待确认]`：仅在材料包明确给出推荐时列推荐结论，否则客观汇总各方向适用条件 + 请客户决策和补充的待定事项
11. `P16 [封底]`：简洁收尾 / 感谢观看

### Variant B: 完整战役模式（大型系列海报 / 全渠道主视觉战役）

1. **封面与目录**：`[封面]` + 极简 `[目录]`
2. **Part 01 项目背景与洞察参考**：`[章节过渡]` -> `[需求回顾]` -> `[趋势洞察]`（独立成页）-> `[同类参考]`（多图并排对比，独立成页）-> `[本品卖点梳理]` -> `[设问过渡]`（按材料实际情况取舍）
3. **Part 02 创意策略与视觉规范**：`[章节过渡]` -> `[核心策略]`（一句话定调页）-> `[策略拆解 / 视觉规范]`（另起一页展开）
4. **Part 03 方案呈现（按创意方向循环）**：`[方向主题]` -> `[创意阐述]` -> `[成品总览]` -> `[场景应用]`（`解释内容：无`）
5. **Part 04 横向对比与决策收尾**：`[横向对比]` -> `[决策与待确认]` -> `[封底]`

## 2. 包装提案 (Packaging Pitch)

Typical use cases: New SKU packaging pitch (multi-direction), brand packaging upgrade across multiple product lines.

### Standard Chapter Sequence

1. **封面与目录**：`[封面]` + 极简 `[目录]`
2. **Part 01 课题解读**：`[项目需求]` -> `[需求聚焦]`
3. **Part 02 洞察思考与竞品诊断**：`[趋势洞察]`（独立成页）-> `[产品卖点回顾]` -> `[竞品包装矩阵]`（多图包装墙并排对比，独立成页）-> `[洞察总结]`
4. **Part 03 视觉策略**：`[核心策略]`（一句话定调页）-> `[超级符号 / 视觉规范]`（另起一页展开）
5. **Part 04 设计呈现（按创意方向或产品系列循环）**：`[命名与定位]` -> `[包装主呈现]` -> `[设计版式拆解]` -> `[色彩与视觉细节]` -> `[工艺与材质建议]`（材料未提则标注 `[待补充]`）-> `[3D多角度渲染]`（`解释内容：无`）-> `[延展与终端陈列]`（`解释内容：无`）
6. **Part 05 横向对比与决策收尾**：`[横向对比]` -> `[货架实景与堆头陈列]` -> `[决策与待确认]` -> `[封底]`

## 3. 视频提案 (Video / TVC Pitch)

Typical use cases: Multi-direction TVC concept pitch (concept boards) OR deep single/dual-direction brand film & storyboard script.

### Variant A: 多方向 TVC 概念比稿（材料包提供多方向 16:9 概念分镜板）

1. `P01 [封面]`：项目名称 + 简洁副标题 + 氛围底图
2. `P02 [目录]`：仅列 3–4 个大板块名称（无页码、无剧透）
3. `P03 [需求回顾]`：核心产品、人群、交付边界与待定条件
4. **前半程双驱动自适应（严格按材料包实际内容选择，不硬造）**：
   - **理性数据驱动**（材料以行业数据+竞品案例为主）：`P04 [趋势洞察]`（独立成页）-> `P05 [同类参考]`（独立成页）
   - **文化意象驱动**（材料以品牌文化资产+感性洞察为主）：`P04 [项目思考]` -> `P05 [破题概念]`
5. `P06 [核心策略]`：极简定调页，一句话抛出材料中的核心策略与核心主张
6. `P07 [镜头与入画规范]`（材料具备时另起一页）：展开片长节奏顺序、品牌入画规范与裁剪延展边界
7. `P08–P13 [各创意方向呈现]`（按方向循环，每方向 2 页，顺序一致）：
   - `[方向阐述]`：保留主副标原文 + 创意切入与策略锚点（**实图防复读**：图上已印有 0–30s 逐帧台词/音效时，此处只提炼结构与亮点，不逐秒复抄；补拍/试拍提醒放入 `内部备注`）
   - `[成品展示]`：16:9 全幅展示原图概念分镜板（`解释内容：无`，标明图号与原图路径）
8. `P14 [横向对比]`：多张 16:9 概念分镜板等宽并排对比，严格基于材料客观列出各方向表现路径与差异
9. `P15 [决策与待确认]`：不擅自替客户拍板首选（除非材料包明确指定）；清晰列出待客户选定的方向及待补规格（媒介、片长、SKU 等）
10. `P16 [封底]`：简洁收尾 / 感谢观看

### Variant B: 深度脚本与分镜提案（材料包提供完整旁白 VO 与多页逐镜分镜）

1. **封面与目录**：`[封面]` + 极简 `[目录]`
2. **Part 01 创意策略与破题**：`[项目思考]` -> `[破题概念]` -> `[核心策略]`（一句话定调页）-> `[策略拆解 / 脚本主题]`
3. **Part 02 脚本呈现**：`[视觉参考]`（Moodboard）-> `[创意说明]`（故事梗概）-> `[脚本结构]`（PART 01–0N 时间轴）-> `[文字脚本]`（完整 VO）-> `[分镜脚本]`（多页 3x3 / 2x4 网格，每格含镜号+画面动作+VO/字幕+分镜图）-> `[分镜总览]`（`解释内容：无`）-> `[影片参考]`
4. **封底**：`[封底]`

## 4. 混合提案 (Hybrid / Integrated Campaign Pitch)

Typical use cases: Poster + Video, KV + Offline Event + Social Comms, Packaging + Integrated Marketing.

### Standard Chapter Sequence

1. **封面与目录**：`[封面]` + 极简 `[目录]`
2. **共享前半程：背景、洞察与总策略**：
   - `Part 01 项目背景与洞察参考`：`[需求回顾]` -> `[趋势洞察]`（独立成页）-> `[同类/竞品参考]`（多图并排对比，独立成页）
   - `Part 02 核心创意策略`：先用 1 页 `[核心策略]` 极简定调，再用 1 页展开各执行模块如何承接该核心
3. **模块化后半程（仅按材料实际包含的模块展开）**：
   - **模块 A（主视觉 / 系列海报）**：套用「海报提案」方案循环
   - **模块 B（视频脚本 / TVC 概念）**：套用「视频提案」对应子路径循环
   - **模块 C（包装设计）**：套用「包装提案」Part 04 循环
   - **模块 D（线下活动 / 传播规划 / 跨界联动）**：活动分区与动线 / 传播节奏表 / 跨界联名玩法
4. **对比、决策与封底**：`[横向对比]`（多方向时）-> `[决策与待确认]` -> `[封底]`
