# 当前中文桌面预览应用

本目录为仓库后续开发入口，来自2026-11-11活跃独立前端的原字节导入。七阶段、既有配色和组件沿用，原scratch目录和4417预览保留，不覆盖较早正式apps源。

开发与配置见[工程入口](../../docs/development/README.md)，使用见[操作说明](../../docs/usage/README.md)，本模块规则见[AGENTS](AGENTS.md)。
