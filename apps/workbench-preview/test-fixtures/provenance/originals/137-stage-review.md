# 阶段评审

## 共同证据

四岗为 visual、brand、user、spread，四对应对抗各核本职断言，不给数值票。裁判、对抗、裁定者均不参与被审稿创作，且彼此独立。实际模型和身份可知信息原样记录，不编造多模型验证。问题写位置/元素、可见现象、对任务的影响、验收条件，区分观察、卡片事实、推断。

独立裁定按问题 ID 处理采纳、驳回及证据；有证硬性问题仍阻断，争议待核。用户审美指定另记 user_selected，不修改事实核验或原票。结构检查、审美判断、策略适配与发布检查分别记录。

## 参考

先定义 component 或 direction 及明确用途。固定本职维度如下。

| 岗位 | 两项维度 |
| --- | --- |
| visual | quality 表现质量、composition 所借构图适用性 |
| brand | compatibility 品牌兼容、translation 主题转译 |
| user | understanding 借鉴机制可理解、feasibility 场景转译可行 |
| spread | memory 记忆机制清楚、difference 指定对照差异 |

direction 两项均适用。仅借材质/配色的 component 适用 visual.quality、brand.compatibility、user.understanding；其他项填写 not_applicable 及理由，spread 只签 boundary_clear 并核禁止整体复制及未声称效果/热度。component 只能 pass_component，不批准整组。整组进入草图仍需主 direction、互补覆盖与无矛盾风格的完整包审查。

1 为已知事实反驳用途，2 为主要借用机制不成立，3 为连接或执行限制缺失，4 为必需检查有图/卡证据且无关键矛盾，5 需指定同类对照更优证据。unknown 表示本阶段外部证据看不到，not_applicable 表示不属于用途，均不填分数。已知缺转译句是 revise_card，不能冒充外部 unknown。

适用必评全部 ≥4，无关键 unknown、无有证硬退才准入，不取平均。整体结构与指定竞品相同而只换产品/文案/颜色并声称创新，或与同品牌同场景历史图相同而只换文案/颜色并声称构图/视角创新，均硬退。先列硬退，再判补卡与未知，独立美术分不被无关硬退连带降低。传播记忆争议需要复核，不靠平均消解。创新只在指定比较范围成立，不声称全市场独创。

核心方向按美术表达、构图、视角和创意载体检查借鉴价值，至少一种有具体对照与可验证转译，不要求每张辅助图同时满足四种创新。参考与草图阶段都要横向检查多个方向，避免同一种机制只换道具。

## 草图、成稿与整体复核

先用途与核心创意，再结构，再美术，最后整体复核。四岗各给 1–5 整体分，四票未舍入均分 ≥4.0；4.5 是更优目标。诊断分不重复加入，不另设每岗 ≥4 或任何岗 ≥3。缺票始终阻断。

必要条件为主题成立、品牌/产品表达适配、节点有效画面关联、创意未妨碍核心理解。关键 unknown 待核，有据硬伤不能用高分抵消。

草图核主角、焦点、取舍、比例、留白、图文层级、文字长度与必要明暗/色块；未精修纹理字体属于本阶段不适用。成稿核实际美术表达，整体复核重新核主次、主题、阅读顺序、必要信息和三方向差异；按问题退回结构或美术阶段。

评审表达按用途、第一眼次序、结构、美术、具体优势、主要判断与 1–2 项修改优先级展开。第一眼自述不是眼动研究，话术齐全不等于通过。
