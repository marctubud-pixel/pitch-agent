# KV 与海报任务

先核传播目的、品牌/产品导向、节点、主 KV/子海报身份、画幅、媒介、必要文案与指定比较范围。同用途主 KV 才进入直接比较；活动现场、促销物料、视频截图等分别标为背景、视觉借鉴或待核，身份待核不凑同类数量。

参考可跨行业，但须回答当前视觉问题。方向卡写可检验的“参考方法 → 目标载体 → 主题/品牌关系”、比较对象和至少一种具体创新假设；参考阶段审假设，草图核兑现。只换标题即可通用于其他节点且缺有效画面关联时退回，节点关联可以由场景、器物、纹理、天气或行为支持，文字可辅助。

草图核主角、元素取舍、位置比例、留白、信息顺序与实际文字长度；创意须帮助核心主张，不以新奇抵消误解或表达损失。成稿核色彩、字体、光影、材质与统一感，按实际风格判断。单图合格后核三个方向是否机制不同，不能只换左右位置或道具。未经实测不声称热度、偏好或传播效果。
