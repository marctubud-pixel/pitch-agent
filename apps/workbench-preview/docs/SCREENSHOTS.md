# Screenshot index · November 3 baseline

The current November 8 experience captures and approved overrides are indexed in [EXPERIENCE-20261108.md](./EXPERIENCE-20261108.md). These older captures remain for comparison.

Baseline captures of the finished interface, produced by `node scripts/shots.mjs` against the demo services. Three variants with identical file names:

- `desktop-light/` 1440px wide, light mode (also contains `--tab-N-…` files for each in-page tab)
- `desktop-dark/` 1440px wide, dark mode
- `phone-light/` 390px wide, light mode

All are full-page captures with reduced motion. The WorkBot character is a fixed element, so it appears at the capture position, not in a layout slot.
