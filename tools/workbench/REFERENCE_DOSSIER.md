# Reference dossier runtime

This unit continues a complete provider-authored copy artifact into a persisted reference selection. It does not implement sketch or image generation. `continueCopy` saves an idempotent intent; `advanceReferences` advances only actual ready jobs after the existing source copy gate.

The dossier stores one frozen full source envelope. Jobs carry its exact ID/hash and return contract. The executor reconstructs canonical input at claim and completion, validates actual source bytes and prior execution receipts, and retains raw request/report bytes outside project snapshots. Changed authoritative inputs create a new edition; prior reports and spending remain visible. A paused dossier stays paused. Spending includes every earlier reference generation in the project, including prior copy editions; restoring old inputs cannot refund calls or bypass an unresolved outcome.

The job tree has director assignment, substantive original copy-owner delivery, reference-owner acceptance, lead plan, three collector children and three image-bearing lead returns. Completed parent calls release their queue slots. Collectors execute the bounded model-proposed query plan through the explicitly configured experimental public HTTP search adapter, then capture discovered pages, fetch only declared images and decode them into the existing managed image store. Search/page/image slots belong to their collector task and persist before dispatch. Original bytes deduplicate within each direction; all observed provenance stays attached. Unknown brand, date and license remain unknown.

The fixed initial plan is 10 production calls plus seven 17-call image panels: three candidate panels, three actual main/complement/backup panels and one three-direction overview. Every panel has separate visual, brand, user and communication first reads, mirrored opposition first reads, scores, challenges and independent director adjudication. Every call attaches at most four original images. Applicable dimensions must each reach 4; whole-direction ranking uses qualification, a Pareto partial order and an explicit task-fit choice. The director cannot raise a role's score. Sketch/final average rules remain unchanged.

Component borrowing has fixed material/color, style, composition, viewpoint/scene and carrier profiles. A component is assessed for its declared local use; it need not solve the complete theme. Missing required local fields remain repairable deficiencies. N/A is constrained by the declared profile; an all-N/A role gives boundary clearance only. Actual direction-level and combination coverage is still required. Profile/model/role/protocol calibration evidence must match exactly. Without that evidence, complete panels remain diagnostic and require a real human adoption of the exact selection. Adoption retains dissent and does not waive unknown images, missing materials or unqualified dimensions.

Machine returns retain the responsible owner, exact original input/report pointer, evidence, impact and acceptance condition. Reference, acquisition and independent-comparison repairs can create at most three bounded revisions; upstream research/strategy/copy findings enter the existing typed artifact correction path. There is no fabricated human feedback. Budgets reserve every seat before starting a generation; known cost is null when unavailable. Unknown provider or tool outcomes remain uncertain and are not automatically retried. Completed slots are reused after restart.

The local HTTP endpoints accept continuation IDs and explicit human actions only. They cannot supply scores, execution contexts, receipts, local paths, configuration or readiness flags. Functional UI shows captured originals, source links, the job tree, original reports, machine returns, pause/resume and actual selection adoption. A successful selection stops at ready-for-sketch (or the authorized reference endpoint) with `SKETCH_RUNTIME_UNAVAILABLE`.

All author tests use synthetic provider responses and injected offline transport with actual decoded PNG bytes. These are development proofs, not business, aesthetic, calibration or consumer acceptance. Native CLI web is not enabled by this unit.

Manual-supplied mode reuses registered project image assets. The human selects an exact copy direction, original image and bounded borrowing profile/note; these are proposals, not factual or scoring authority. The original hash, dimensions, declared purpose and manual provenance enter the frozen envelope. The collector accounts for every proposed use and the lead explicitly accepts or returns its resulting use cards. A single image may support multiple declared purposes but counts once as an original. Removing or adding a material preserves historical editions and spending. The source copy gate still precedes all consuming-module calls, and active or unknown outcomes cannot be bypassed with a material change. Manual mode has zero query calls and no automatic-search acceptance credit, including when automatic discovery is unavailable.

The only computation cache is a bounded map of 128 complete pure panel outcomes. Its identity hashes the actual packet, actual raw reports and calibration flag; stored claimed hashes are not its identity. Values are copied on insertion and retrieval. It does not cache authoritative source currentness, receipt validation, saved request/report bytes, calibration files or managed image bytes. Those checks still run at the execution boundary. This preserves the accepted contract and makes no measured performance claim.
